# Stormline: Black Tide / 黑潮回收

- 独立桌面 3D 项目，Godot 4.3 Compatibility；不属于网页游戏总站及其版本或站点部署。
- 不启动图形游戏客户端，不使用桌面自动化，不抢前台；允许 Godot 的无窗口导入、脚本回归和导出。没有远端发布目标时不自行创建公共仓库。
- 并行工作按文件隔离。模拟器无场景/磁盘依赖，场景和 HUD 消费同一份快照；坐标为米，航向零指北，屏幕大小不改变模拟。
- 不提交 `.buildtools/`、`.godot/`、`.testdata/`、`build/` 或用户档案。验证需区分无窗口回归、实际桌面试玩、已生成的可执行包和对外发布。

## 阶段同步与继续开发（2026-11-20）

- 用户授权自主决定开发、测试和迭代，不把常规技术选择或阶段继续推进交给用户确认；不要以等待用户验收为开发终点。没有执行的实机检查仍明确标为未测，不冒称已通过。
- 每个完成且验证通过的阶段，立即同步到已有 GitHub 总仓库 `xxsxjt/xxsx-web-games` 的 `desktop/stormline-black-tide/`，保留仓库既有 LICENSE 和历史；不另建仓库、不强推、不改网页发布或存档。
- 本目录是本机开发源；总仓库子目录是逐阶段、内容核验的源码镜像。仅复制明确列入清单的源码、测试、工具与文档，不复制本机产物、凭据、缓存或玩家档案。
- 每次推送前 fetch 并检查远端差异，验证本阶段；推送后读取远端 commit 与文件树，逐文件 Git blob 比较。没有远端读回证据不能称为同步完成。
