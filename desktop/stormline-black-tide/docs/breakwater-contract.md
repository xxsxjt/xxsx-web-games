# 第三合同：碎潮回廊

合同 ID：cross-current。这是拖带模拟器中的独立高阶航线：从东南港口出航，前往西北回收舱，绕过挡住直返线的断桅礁，在西折涡和东横流的交叠水域自行取道，再将拖船与回收舱一同带回东南港圈。限时 215 秒，所有正式航点及危险物都在模拟器 ±140 米世界范围内。

## 航线抉择

- **南脊安全绕行**：出港后由断桅礁西侧远绕，离开两个流场核心再接近目标；返航沿南侧外弧宽转弯，避开东横流核心及南门礁。航程较长、耗时较多，操舵宽容。
- **东横流捷径**：从礁东侧抢切并穿过交叠流带；返程反向走急弯切过东流核心。自然固定步长驾驶约快 19 秒，但中段会遭遇显著横流，需要控速并留意拖舱转弯。此路线仍在模型限时内自然可交付。

tests/breakwater_journey_test.gd 暴露可复用的纯控制 Pilot 接口：

    const Pilot = preload("res://tests/breakwater_journey_test.gd")
    var route_index := Pilot.route_index_for(snapshot, leg, route_index, route_choice)
    var controls: Dictionary = Pilot.controls_for(sim, leg, route_index, last_tow_input, route_choice)

ROUTES 提供 safe / shortcut 两种 outbound 与 return 的 Vector2 航点；ROUTE_WAYPOINT_RADIUS 为 7 米。调用方维护 leg、route_index、last_tow_input，将控制字典经目标应用的正式输入边界送入模拟器。函数只读快照，不推进、重置或写入模拟状态；自然航次固定步长为 1/60 秒。

## 无窗口自然航次证据

使用官方 Godot 4.3 --headless --audio-driver Dummy，从正常 reset("cross-current") 初始位置开始。测试只调用完整自然航行控制：驶向信标，低速扫描，接近漂流舱体后以挂索边沿输入系缆，随后按航点带载返航并完成稳定进港；不瞬移、不改位置/速度/资源/计时/天气/终态或成绩。

| 选择 | 终点 | 时间 | 峰值张力 | 路线证据 |
|---|---:|---:|---:|---|
| 安全绕行 | 9204 tick，成功 | 153.40 秒 | 0.461 | 拖带段距任一流场核心最近 39.80 米，未入当前核 |
| 东流捷径 | 8064 tick，成功 | 134.40 秒 | 0.454 | 实际进入流场核心，最小距 14.34 米 |

两个路线均以 60 tick、低速、低张力停泊稳定交付；安全路线自然耗能较多，捷径更快且余电较高，但承受更直接的流场暴露。测试另以自然静置模拟到 215 秒，观察到正式 timeout 失败结算及空成功报告，并重开确认位置、舱体、资源、扫描、拖带、事件和成绩报告全部清零。

原两合同的完整参数字典与固定控制输入 120 秒的自然模拟快照也作为回归基线逐项断言。该证据仅证明确定性模拟器控制路径和合同数据兼容；不代表主场景/HUD/快捷键/成绩存档接线验证，不代表图形、声音或真人操控体验。
