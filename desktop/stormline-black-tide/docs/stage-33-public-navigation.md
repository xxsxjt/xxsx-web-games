# 阶段33：公开航路航点与手动导航

日期：2026-11-26；源码 v0.2.7。本阶段将船坞备航选择接到现有实际驾驶／HUD／雷达，不增合同、部署、寻路或持久系统。最终双侧验证与远端回读详证在本机 `build/sync/stage-33-evidence-index.json`，成功回执前不称同步完成。

## 玩家闭环和边界

- 船坞「公开航路」及驾驶台原生下拉／按钮提供港心、公开搜索区中心、当前可取样潮站和具名公开礁石东西侧外18米参考点；最多12条可选路线，每条最多3点。绕礁路线依次参考点→搜索中心→港心，不承诺段间净空或最优。搜索中心不是舱位。
- N 换线、B 手动下一点、C 清空，与原驾驶键及别名不冲突。应用只管理当前路线ID／序号，纯投影只读 harbor／beacon／hazards／tide_survey／position；不读 target、cargo_position 或私有模型。到点8米内提示，不自动换点、扫描、取样、挂索或交付；最后一点手动下一后显示走完而非完成合同。已完成潮站变为不可用，手动选择下一站。
- 距离从实际船到航点，北0°／东90°顺时针方位；同点无方位、小非零距离显示<0.1m，方位整数舍入后模360。雷达独立黄色空心环／图外开口标记，不画导航线、不变北向图心和范围；图外行角度从图心出发，驾驶台角度从船出发，船距不按像素算。原未知舱不公开、图外船舱距离和无截边实线拖缆仍保留。
- 船坞路线仅在原确认保存成功后带入同合同驾驶。换报价／重读／返坞／重开／换模式／终局清空；暂停或失焦保留冻结，旧导航键须释放再按，忽略重复和暂停操作。下拉不自动暂停，仍使用原真实驾驶模型；想停下观察应先P。路线不写盘、不改变资源／功率／控制、不确认工单或出航。
- Sim／Catalog／Damage／State／Store／Records 保持原字节；v1身份／字段／存档路径／历史事件、三合同最佳和sidecar不变。Stage32草案仍未付费、可撤销，原act顺序定价，明确确认后单次保存；CAS仍为观察式冲突检查而非跨进程原子锁。

## 验证方法和实际状态

新增纯投影和正式main应用套件，追加在原QA后。纯夹具覆盖三合同和全部远征报价分支、未知／锁定舱不影响导航、输入只读、路线数量／步数、方位四象限／重合／负坐标／舍入、截边不改图心／比例和当前潮站可用性。

正式原生按钮覆盖航前选择、实际出航传递、工单仍未提交、保存字节／模拟资源不变、驾驶台下拉／下一／清空、合成N/B/C与暂停持键／失焦，以及重开、换约、实际成功／失败和返坞清空。四个支持视口检查长标签、原生滚动／焦点和驾驶台雷达共存几何，不是渲染或中文可读性验收。实际付费制图合同从正式起点用连续Pilot油门／转向航行到公开绕礁点，与独立同spec模拟逐tick、导航与公开快照逐样本对照；无瞬移或任务注入，不是全程数字键或真人驾驶。最终结果由完成报告列明精确命令、日志、失败尝试和源码指纹。
