## 玩家得到的系统

- 原任务台 X / 远征按钮 → 明确新建/继续 → 船坞三海区六部署 → 分支/风险合同 → 实际扫描/挂索/拖带交付 → 持久报酬与耗损 → 付费维修/充电/改装 → 后续旗舰回收或明确撤退。
- 勘测降低后续海况/舱重、拓宽窗口，打捞即时给更多资金和材料；保守/冒险改变真实模拟而非只换标题。整备与航次推进增加压力，单纯停在菜单不增加压力。
- 推进/稳索/声纳共两槽、负载预算 3，推进与稳索两重模块不能同时装。推力、能耗、声纳、拖缆额定/船重影响原 `step`；没有平行模拟器。真实船体/电量进入下一次部署，维修/充电会花预算、材料或压力。
- 先保存部署/航费再运行；真实成功或失败按 token 结算一次，写失败显示尚未入账，冲突不覆盖新档。主动放弃基于当前实际耗损再扣救援，中断重载仅按出航登记救援返坞，不恢复最后驾驶帧。
- 三合同快玩、旧最佳/sidecar 和内存复盘保留；快玩 R 原样，远征 R 禁用。远征单独使用 `stormline-expedition-v1.json`，不迁移旧成绩、不启动即建档、不覆盖坏档。
