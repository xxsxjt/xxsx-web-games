# 阶段 05：双体擦礁冲击冷却

日期：2026-11-20。通过复用阶段 04 六处礁石的碰撞夹具，扩展验证拖船与自由回收舱同时或重复接触时的损伤和提示节流。

## 缺陷与修复

原模型用一个碰撞计时戳同时控制拖船与尾舱的冲击损伤和 UI 碰撞提示。两个物体在同一物理 tick 同时触礁时，第一个分支更新计时戳，另一个分支因此跳过冲击损伤；两个物体仍会承受持续接触损伤，导致只看最终状态容易漏检。

现在拖船与尾舱分别维护 0.54 秒冲击损伤冷却；提示文本仍由单独的共享碰撞提示冷却节流，避免同一帧两条消息互相覆盖。每个对象仍只对有效入射速度触发冲击损伤。

## 回归

`tests/cargo_tow_test.gd` 对两个合同的六处礁石新增共 48 项断言：同时碰撞后两对象均各自推离并收到正确冲击损伤；同一碰撞冷却时间内再次接触只增加持续损伤、不会重复增加冲击伤害；碰撞反馈仍只发出一条消息。聚焦套件总计 **112 项通过，0 失败**。原 64 项阶段 04 结果仍在覆盖范围内。

无窗口回归使用 Godot 4.3 Compatibility 引擎，不启动 EXE、不实例化主游戏场景。完整 QA 与候选包必须使用最终记录的同一源码指纹；此前阶段 04 的 ZIP/PCK 不包含本修复。
