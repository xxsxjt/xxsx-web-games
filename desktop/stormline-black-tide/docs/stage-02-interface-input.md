# 阶段 02：低分辨率 HUD 与键盘适配器

日期：2026-11-20。该阶段只改独立 Godot 项目的界面适配、键盘输入及隔离回归；网页入口、网页存档和浏览器站点未变。

## 找到并修复的问题

- 新增 4 种视口尺寸 × 6 种游戏界面状态的程序化 Control 矩形检查。首轮 232 项中 14 项失败：1280×720 面板互相遮挡、960×600 任务台与结算面板越界、低分辨率驾驶区面板交叠。
- HUD 新增 1440×900 基准画布自适应；小视口按统一比例缩放界面，不缩放世界或改变模拟。修复后 232 项全部通过。该检查不渲染画面，不验证观感、字体实际字形或鼠标体验。
- 任务台增添 1/2 数字键选约。主输入回退使用 `physical_keycode`，覆盖无字符/物理键码事件。
