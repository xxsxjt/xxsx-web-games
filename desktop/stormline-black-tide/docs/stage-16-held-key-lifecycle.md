# 阶段 16：持键暂停/失焦、恢复与重开

日期：2026-11-20。新增 `tests/needle_held_lifecycle_test.gd`，纳入完整 QA；本阶段不改生产输入、物理、合同、界面、音效或成绩规则。

## 方法与覆盖

- 沿阶段 15 的六 tick 三轴离散采样驾驶自然针礁航次；每个导航 tick 均调用正式 `_physics_process(1/60)`，不向应用直接传控制，不注入船舱位置、资源、天气、停泊或报告。
- 从正式合同开局实际扫描、挂索并撞中央针礁。碰撞后持有 Godot 进程内 W/D/Q/E/Shift（推进、右转、收缆、扫描、慢车），经合成 P 或失焦回调暂停；暂停期间保留或释放这些键。
- P/失焦 × 保留/释放 × 恢复返港/恢复后过载/R 重开/回任务台再开航，共 **16 档**。暂停时以 1/60、0.75、60 秒 delta 调用物理/呈现回调；重复失焦、Space、功率边沿不得推进模型、改变任务或写成绩。
- 六条同输入不中断基线：恢复与过载各分持有/释放，重开新任务也分持有/释放。恢复首 tick 或新任务首 tick 真实轮询当前键状态，随后接回正常离散驾驶。重开仍持有的导航键可以生效，旧任务排队的 Space 不能重放。
- 独立模型、路线与离散采样器逐 tick 核对完整公开快照及只读碰撞/提示时钟，最后比较基线的完整碰撞与终态。模型仍使用相同生产模拟器，不是独立物理实现。
- 仅使用 `.testdata/needle-held-*` 隔离成绩目录；真实成功才写入测试最佳。暂停、放弃、重开、失败与不优于基线的重复成功均逐字节保护已有最佳，并重新读取排名；最后仅清理本次目录及合成持有键。

| 同输入基线 | 终态 tick | 实际结果 |
|---|---:|---|
| 原航次恢复，首 tick 释放 | 8232 | 受损双体低速、低张力入港，稳定 60 tick；船体 80.3 / 舱体 78.4 / 电量 42.5 |
| 原航次恢复，首 tick 持有 | 8232 | 同样实际交付；船体 79.9 / 舱体 77.7 / 电量 42.5 |
| 原航次过载，首 tick 释放 | 4520 | 真实持续过载断缆，无成功报告 |
| 原航次过载，首 tick 持有 | 4519 | 真实持续过载断缆，无成功报告 |
| 重开新航次，首 tick 释放 | 8229 | 正常扫描、挂索、触礁、受损返港；碰撞 tick 4240 |
| 重开新航次，首 tick 持有 | 8229 | 正常扫描、挂索、触礁、受损返港；碰撞 tick 4245 |

首 tick 控制不同导致资源或新航次碰撞 tick 不同是预期；只要求暂停/重开档与**同输入**基线完全相同，不强求不同控制得到同结果。
