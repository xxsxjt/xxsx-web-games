# 碎潮回廊：玩家航路提示

碎潮回廊是第三份独立合同。任务台选中「碎潮回廊」后按 Enter 开航；屏幕上的北向上雷达为航路参考，方向仍用驾驶台航向和船头表示。

## 目标与操作

1. 从东南港口驶向西北橙色信号区。低于 5.5 m/s 时按住 E 扫描；锁定后接近漂移的回收舱，在 15.5 m 内、船速不高于 2.9 m/s 且相对速度不高于 4.2 m/s 时按 Space 挂索。
2. 挂索后用 3「稳索」和 Shift 慢车控制拖船，Q 收绳、F 放绳。拖舱急转前先松油门；注意尾舱摆幅、礁区和流场，张力达到额定线时减载。
3. 船与舱都要进入青色港圈，速度均不高于 2.6 m/s、缆张低于 68%，并连续保持 1 秒。成功结算保存本合同最佳成绩；失败不写成绩。R 重开当前合同，结果页 Enter 返回简报。

## 流场标记与航路风险

海图将两个流场中心标为 **1 西折涡** 和 **2 东横流**；圆环上的数字与海图下方同编号读数对应。每行分别给出拖船与回收舱离边界的状态和距离：「圈内」表示当前位于标示流场范围内，「圈外」表示尚未进入。「<1m」保留刚过边缘的状态，避免整数四舍五入成零时误读为已在圈边；恰在边线上标为「圈边」。未扫描前只显示「舱未锁定」，不会显示隐藏舱体位置。数值只描述当前位置，不预言流速或伤害，也不改变航行规则。

- **南脊宽水绕行**：尽量让拖船及拖舱保持在两个流圈外侧，航程较长但弯道余量宽。读数会在船舱移动时更新，可用来确认绕行空间。
- **东横流捷径**：从断桅礁东侧切入并穿越东横流，返航也会经过流场核心；读数变为「圈内」是实际暴露提示。降低转向速度，提前留出拖舱回转距离。

雷达数字只标识流场地标，现有圆环继续表达礁区/流区轮廓。第三合同之外的旧航线保持原有海图显示。两条路线均可完成合同；该提示只帮助玩家把航迹与任务简报中的地名对应，不替玩家选择路线。

## 键位

- W/S 或方向键上下：前进 / 倒车；A/D 或左右：转向。
- E：按住扫描；Space：挂索；1/2/3：推进 / 搜索 / 稳索。
- Shift：慢车；Q/F：收绳 / 放绳；P 或 Esc：暂停 / 继续；R：重开；M：静音。

本页是操作说明，不是桌面运行实测记录。无窗口自动驾驶、成绩持久化和靠港生命周期的验证见 `tests/breakwater_journey_test.gd` 与 `tests/cross_current_app_test.gd`。
