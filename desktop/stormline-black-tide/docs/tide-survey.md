# 远征：实测潮道

阶段 27 / v0.2.1。基于已同步的阶段 26 (`7b2de90`)；冻结候选已按显式白名单接入规范源与桌面镜像，两侧最终验证和远端同步分别见 [集成记录](stage-27-tide-survey.md)。下方候选证据保留其原始验收时点，不冒充最终规范源或远端结论。目标是让航线取舍发生在驾驶途中，而不只发生在船坞。

- 原六个部署节点及「潮标回收」「打捞」仍在。在每个海区的首部署可改签「实测制图」：沿海图顺序去 A、B 两个已知测站，进入测区、降速并按住 E 连续取样。松键、越界或超速中断当前样本，不丢先前完成的样本。按原规则锁定、挂索、拖回整艘回收舱之后，制图才真正入账；失败或主动放弃仍走原资源与救援规则。测站不传送、不补电、不替代搜寻和拖带，雷达不提前揭示回收舱。
- 实测签约成本高于潮标回收，并要绕航、耗时、耗电；脉冲声纳可加快低速取样但仍需付电量代价。想较快、便宜出航仍可回收潮标，缺周转资金或材料可选打捞。成功制图留下一条真实选择：同区主回收（含旗舰）可利用已记录的缓流时窗，实际削弱局部漩流项；同一部署的基础风、漂移和拖缆等仍由原模拟驱动。预测报价不声称整个海面永久减弱。
- 持久证明用正常交付路径中的 `*-chart-safe/high` 合同 ID：旧 ID 的 v1 档案、令牌、价格和原报价公式不改；新版本可继续读阶段 26 档案，不自动迁档、不覆写旧成绩。写入含新合同 ID 的档案后不能倒回不认识新 ID 的 0.2.0。出航登记仍不保存末帧，不能通过重载保留或重复领取测站进度。
- 验收：独立规则边界和正式入口/真实档案/驾驶六部署；测站位于同一海面，连续取样可由正式 E 输入达成；对照旧与新报价及局部流速、放弃和失败不增加路径；同步前确认三个旧快玩、旧远征路和旧档案可用。只运行隔离 headless / CLI；资源探针不启动主场景，无真人/图形试玩、EXE/ZIP 或 Sites 部署。
