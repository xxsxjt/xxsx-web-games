# 远征任务目录与真实驾驶

实施边界：只修改候选的 `src/storm_sim.gd`，新增目录、模拟回归和本文。Stage25 旧合同、快玩 API、Pilot、成绩及场景逻辑保真；不改规范源、镜像或 Git。

## 实施计划

1. 先定目录、船坞和快照接口。目录不引用模拟器，预览与实际出航用同一份白名单覆盖；三套海域几何由旧合同深复制。
2. 将持续船体/电池、推进、能耗、声纳、拖缆和船重接入现有物理。一次验证完整出航参数后才重置；不复刻天气/碰撞/终态规则，不改驾驶阈值。
3. 以同输入逐帧对照 Stage25 三合同；核对目录预览、模块负载和效果、非法配置原子拒绝、回快玩脱离远征。用原输入 Pilot 从自然出航完成两种构筑，配合正式应用验证六次连续部署。
4. 仅官方 Godot 4.3 headless，命令显式日志、子进程目录隔离，夹具仅候选 `.testdata`。读回 UTF-8 和 SHA-256 后冻结四文件；真人图形驾驶和发行不在此次验证范围。

## 任务选择怎样影响实际驾驶

| 海区（`sector`） | 支线 `leg=0` 二选一 | 主回收 `leg=1` | 实际底图 |
| --- | --- | --- | --- |
| 1 黑潮水域 | 防波堤潮标勘测 / 失事补给舱打捞 | 黑潮航路主回收 | `black-tide` |
| 2 针礁水道 | 针礁流标勘测 / 针礁储备舱打捞 | 针礁航路主回收 | `needle-bank` |
| 3 碎潮回廊 | 碎潮交汇区勘测 / 外海储备舱打捞 | 旗舰回收：风暴线号 | `cross-current` |

- 每个节点可选保守或冒险。冒险版出航多扣 8，报价多 26～35，通常加 0.095 基准海况、0.39 舱重、缩短 12 秒窗口、改变来风方向；海况有上限。实际结算按档案规则和交付完整度计算，不把报价当到账金额。
- 勘测和打捞都需亲自按顺序扫描、挂索、带载返航。勘测带回潮标观测，让同区主回收更轻、浪更小、窗口更宽；打捞多给资金和材料，但少了潮标情报。跨区保留较弱的情报效应。成功路径只接受当前节点以前的合法合同 ID，不能跨区抢跑或重复使用旧报价。
- 整备、航次推进和失败等档案操作可积累压力，停留在菜单并不会增加压力。每个生效压力点使基准海况约 +0.009、湿舱质量约 +0.022、期限约 -1.35 秒；12 点后物理影响饱和，档案仍可记录更高压力。数值取整和上限统一由目录处理。`severity` 是出航海况基准而不是整航次固定值；旧天气函数再按航次时间计算浪、风和流场。舱重进入牵引加速度，期限仍由同一失败判定执行。
- 没有新增另一套地图或任务模拟。`offers()` 的参数就是 `build_contract()` 的覆盖项，`summary` 只供预览。Sim 校验后深复制对应三合同之一，再覆盖白名单；原几何直接交给既有 `world.configure(sim.contract)`。

## 改装取舍

| 模块 | 价格 / 负载 | 同一个 `step()` 中的实际效果 |
| --- | --- | --- |
| `drive` 增压推进器 | 96 / 2 | 油门推力 ×1.15，总耗电 ×1.16；慢航控制器仍以旧目标速度制动 |
| `tow` 稳索配重架 | 92 / 2 | 各工况拖缆额定载荷 ×1.25、横向阻尼系数 ×1.14；拖船质量 ×1.09，转向与加速度响应随之减弱，回收舱质量不由此模块修改 |
| `sonar` 脉冲声纳 | 48 / 1 | 各工况声纳输入系数 ×1.46，原扫描窗口中更快锁定；扫描负载增加，总耗电 ×1.07 |

空载即 `[]`，`stock` 不是可装备模块；两槽、总负载 3，所以稳索不能与推进共装。`drive+sonar` 购置价 144，配置时尽早规划充电；`tow+sonar` 购置价 140，长航次保留电量、承受重载更有利，但换向更慢。各乘数乘在它们对应的量上，不能把声纳系数当扫描总速率、慢航目标当硬速度上限，或把额定载荷当成入港时允许的绝对力。

## 对接与兼容

- `Catalog.offers(sector, leg, path, pressure)` 和 `Catalog.build_contract(offer_id, pressure, path)`：海区 1～3，航次 0～1，前缀长度 `(sector-1)*2+leg`，压力为 0～99。ID 为底图 ID + `-survey-` / `-salvage-` / `-recovery-` + `safe` 或 `high`；第三区主回收 ID 仍用 `-recovery-`，公开 `branch=flagship`。`Catalog.sector_name(sector)` 供未解锁地图直接使用。
- `reset_expedition()` 接受状态模块构造的内存 `token/offer_id/contract/loadout/hull/battery/pressure/path` 八键字典。校验部署标识形状、合同重算和字段类型、合法装备及 `(0,100]` 有限船体/电池；更严格的最低整备和一次结算是 State 责任。非法调用不重置已有航次；合法启动使用真实船体与余电，不把未校验覆盖字典用于物理。
- 远征快照才有 `expedition`（报价/覆盖参数、`token/offer_id/base_contract/loadout/pressure/path/initial_hull/initial_battery`、组合 `effects`、当前有效 `profile`、实际 `thresholds`）；顶层 `expedition_token/offer_id` 供状态模块对齐出航。`contract_id` 始终是底图 ID，应用在远征走独立结算，不写快玩榜。快玩 `reset/step/snapshot` 字段及覆盖以外规则不变；返回快玩撤销全部改装和远征状态。
- 扫描距离 ≤27 m、船速 <5.5 m/s；挂索距离 ≤15.5 m、船速 ≤2.9 m/s、相对速度 ≤4.2 m/s。入港仍要求船舱都在圈内、两者速度 ≤2.6 m/s、额定张力比例 <0.68、连续 1 秒。拖缆过载、碰撞、期限、资源耗尽、终态优先级和评分公式保留。
