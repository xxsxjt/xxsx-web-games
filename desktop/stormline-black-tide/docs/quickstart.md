# 风暴线：黑潮回收 / Stormline: Black Tide

v0.2.9 · 源码阶段 35 · 2026-11-26（无完整 Windows 候选；上航参考与验证状态见 `stage-35-voyage-reference.md`，整备／导航／航段／损管／制图规则仍见对应说明）

## 启动（仅适用于另行提供完整候选包时）

1. 将完整 ZIP 解压到一个可读目录。不要只从压缩包内打开 EXE。
2. 保持 `Stormline-Black-Tide.exe` 与 `Stormline-Black-Tide.pck` 在同一文件夹，然后双击 EXE。无需安装 Godot；无需登录或联网。
3. 默认进入任务台。先选「黑潮回收」熟悉拖带，再尝试「针礁水道」和「碎潮回廊」。按 1/2/3 选择快玩合同，Enter 开航；按 X 或点「远征 / 继续远征」进入独立经营档案，也可使用鼠标菜单。

若系统阻止运行另行提供的候选包，先核对来源与 `SHA256SUMS.txt`；不要关闭防护软件或绕过安全提示。资源探针 PCK 不是完整可玩候选，本阶段未生成或运行游戏 EXE。首次图形启动、显卡兼容、中文字体、操控和音量仍未实测；旧版记录不代表此版本通过。

## 远征：先经营，再实际出航

1. 任务台 X 打开只读档案页；无档时明确选「新建损管远征」，有档选继续。仅打开菜单不会创建或修改档案。旧档沿用旧物理，需在船厂明确确认才能启用损管，扩展后不可用旧程序读回。
2. 三海区每区先做潮标勘测、打捞、实测制图三支线之一，再做主回收；仍共六部署，第三海区主回收是旗舰。保守/冒险报价改变真实海况、舱重和限时。原勘测较省航费和路程，打捞即时多赚材料，制图花更高航费和绕航为同区主回收取得额外局部缓流。
3. 在整备页购买、装备推进/稳索/声纳，最多两件且负载不超 3，不能同时装两个重模块。维修消耗资金和材料，充电消耗资金，两者都推进压力；船体和电池原样带入下一次实际驾驶。模块也有动力、能耗或质量代价。
4. 选报价、确认出航才扣费并保存部署，再进入与快玩相同的扫描/挂索/拖带/双体入港流程。远征驾驶台显示当前真实门槛；声纳和模块改变能力，不降低挂索或靠港判定。下文具体数值描述原快玩标准配置，远征以该航 HUD 为准。
5. 成功结算报酬/材料并保留耗损；失败没有报酬，已完成节点保留。R 在远征禁用；暂停可继续或确认放弃，放弃按当前真实耗损另扣救援代价，不退航费。船坞可明确撤退，终局可明确另起远征，不暗中补给。
6. 「尚未入账」不是保存成功：写盘故障只能重试同一结果；另一会话已更新档案时需明确舍弃本机结果并重读，不合并或覆盖。重载 active 档只按出航登记扣救援后返坞，不能恢复最后驾驶帧，也不承诺抵抗故意杀进程回档。完整规则见 [远征应用说明](expedition-interface.md)。

### 先做整备工单，再决定是否花钱

船坞「整备工单」可将维修、充电、模块购买／安装／卸下、预装／卸回封堵包按顺序加入草案，最多12项。看清资金／材料／船体／余电／装备和结构破口的前后值，以及压力对当前所选合同海况、舱重和窗口的实际影响；也会显示整备后能否支付航费及余额。可撤销最后一项或清空，未确认前不扣费、不改变存档。购买后还要再加入安装，不能装两个重模块；不能先花后一步才退回的材料。

「确认整单」再按「保存整单」，所有操作一次入账、修订号只加一，各项原有花费和账本仍保留。取消保留草案；写盘失败无半单扣费，可修复路径后再次确认。陈旧档冲突只能明确重读，草案不合并到别人的新进度。草案只在内存，不是中途存档；返回任务台／退出会先确认舍弃。存在草案时出航与原船厂单项动作暂停，须先提交或清空。原船厂即时整备仍可使用；工单不自动优化路线、不保证余电够用或任务成功，付费维修／充电仍推进风暴压力。

### 上航参考：已入账实测，不是下一航预算

真实付费且已保存的出航，从实际初始化快照开始逐步测整航；成功或失败的**对应结果实际保存入账**后，才替换唯一一份「上航参考 / Last voyage」。返坞打开「整备工单」，左侧是原本的当前已存资源 → 未保存草案／所选实际报价，右侧是旧航实测。可原生「收起／显示参考」、选「整航实测」或上航保留的一个完成段，并可「清除参考」。这些动作不改草案、不扣费／保存、不维修／充电／出航。新参考默认显示整航；选段只属于这份旧航，不会跳到以后航次的同号段。

整航行程独立按每个实际物理步公开船位累计，包含终局末步；不是端点位移，也不是手动段之和。没有手动段会明确写「上航无手动完成段」，整航仍有效。船体与电池净变单位为有符号百分点；旧档缺耗电分账或中间缺失／回退，实耗显示不可用，真零仍为测得零。失败实测止于终局，**不包含后来救援额外扣船体**；左侧当前资源则是已存且含救援代价的值。只留端点公开风／风暴，不推断原因、环境流、优劣路线、下一航成本、最低储备或续航安全。

待保存／冲突时保留上一份有效参考，不将本次未入账结果冒充已保存；重试仅在原结果成功保存后提升一次。放弃和中断不生成新参考。新付费出航、换报价和工单／船厂服务可保留旧参考供下次返坞，驾驶中不当成当前遥测。明确清除、重读／舍弃重读、成功新建／另起远征或切回快玩会清空；关闭重开丢失，不从账本恢复。阶段34本航手动段仍实际返坞即清空。

### 公开航路：备航选择，手动驾驶

船坞「公开航路」页按当前报价提供港心、搜索区中心、当前可取样潮站，以及具名礁圈东西侧外18米的参考点。选绕礁路线会按「参考点→搜索中心→港心」最多三点排列；搜索中心**不是舱位**。出航仍须原确认并成功保存，导航不提交工单、不购买服务或扣费。换报价、重读、返坞、终局、快玩重开／换约清空路线；暂停／失焦只冻结保留，退出不保存。

驾驶台顶部中央显示当前点、实际船距（米）和北0°／东90°顺时针方位；同点显示无方位，极小非零距不显示零。下拉可换线，N 轮换可用路线，B 手动下一点，C 清空，也可点击原生按钮。到点8米内只提示，不自动推进；B 可在任何位置手动跳到下一点，最后一点后显示手动走完，并非完成合同。完成当前潮站后原点不可用，请手动换到新潮站；仍须按原速度／范围长按 E 取样。暂停时不接受导航动作，恢复先松开旧导航键再按，避免持键触发。

雷达黄色独立空心环是导航点，不是舱位、拖缆或安全走廊；不画导航连线，不改变北向上图心／比例。图外航点沿用图心方位截边，船距仍是真实世界距离；驾驶台北基准方位则从**船指向航点**，二者原点不同。参考点只由已公开礁心／半径构造，没有检查途中船舱净空、未知危险、风流和电量；仍需留意尾舱切弯。选择／近点均不代替扫描、挂索、取样或稳定靠港，不保证返航或最优路线。下拉菜单不自动暂停，需停止观察时先按 P。

### 手动航段：记下刚才实际发生了什么

仅远征实际驾驶中，中央原生按钮或 **J 开始、K 完成、L 取消**。一次一段；活动时显示模拟秒和逐步行程。重复开始不重置起点，无活动完成／取消不留记录；同一模拟时刻完成如实记0秒／0米。取消只丢弃活动段。最近6个完成段在 P 暂停和实际结算的原滚动页并列展示，第7段替换最旧段，编号不回用。到导航点不自动结束观察，也不取样或完成目标。

行程是每个真实物理步公开船位之间的距离之和，单位米，**不是端点位移，也不是精确连续弧长**；时间为模拟秒。船体与电池显示有符号「百分点」（80%→77%为−3百分点），电池净变不等于累计支出。支持耗电分账的损管远征另显示本段实际累计支出差「电量点」；旧档无该公开扩展显示不可用，不冒充零。任一采样缺失／回退后该段实耗保持不可用，后续重现也不拼接。两端风为公开(东,南)分量 m/s，风暴为百分比；没有环境流速／流向读数。不把损失归因于风／礁／路线，不预测续航或推荐路线。

暂停／失焦冻结航段，只可查看；恢复先松开旧 J/K/L 再按，避免持键重放。成功或失败按最后真实公开快照收尾一次，并在该结算保留；返坞／任务台、重开、换航次／合同／模式、重读档案均清空。仅内存，不跨退出保存，不修改船体、电池、控制、存档、目标或原事件复盘。控件不自动暂停；需要从容比较先按 P。极小非零变化用 `<0.001` 保留方向，不将其舍入成零。

### 实测制图不是到站领奖

选择制图后先看雷达上的 A、B，当前世界测站有浅蓝标记。依次进入 13 米范围、船速严格低于 4.0 m/s，按住 E 连续取样；标准搜索档约 2.5 秒，声纳模块可加快，但开机耗电更高。松键、越界或超速清零当前未完成样本，已经完成的 A 不会丢失。途中松开 E、留足返程电量；尤其第三海区的宽水绕行可能非常吃紧。

两站完成后才能用 E 锁定橙色搜索区内的回收舱，再照常挂索和拖回港。只有成功且保存入账的制图，才让同区下一主回收的局部涡流项变为普通值的 70%（保守制图）或 60%（冒险制图）；不直接减少基础漂流或风。失败、放弃、重载中断及尚未入账结果不授予持久时窗。新版本读取原 v1 远征档；写入新的制图合同 ID 后，不要用不认识该 ID 的 v0.2.0 打开。

### 海上损管不是免费修船

新损管远征的拖船触礁会留下跨航次结构破口，持续进水并减弱动力/转向，水位 100% 失败。船厂可预装至多两包（每包转入 1 材料，未用可卸回）。G 切换排水泵，实际抽水耗电 0.45/秒；H 连续封堵 5 秒，要求每步更新前后船速都严格低于 2.2、油门绝对值 ≤0.05 且缆张 <68%。松键、超限、再次擦礁中断工作，完成才耗一包；持续按住不会连耗第二包，仍有破口与材料时须先松开 H 再按住。驾驶舱列出公开快照可判断的当前阻碍，提示不代替实际施工和碰撞判断。每包暂封最多 1.0，不回血或修复结构。

入港排干积水但不会修复破口；下一航次临封清空，会重新进水。原 14 资金＋1 材料、压力 +1 的维修除最多 +25 船体，还修复最多 1.0 结构破口。失联中断不保存末帧，按登记救援时所有预装包损失、破口另 +0.35；有真实快照的放弃/失败则保留实际剩余包和破口。具体成本和验证边界见 [损管说明](damage-control.md)。

水位还会放大油门推进电耗，松油门没有该项附加费；待机、声纳、拖带和水泵不乘进水倍率。驾驶舱的「上步耗电」是上一固定模拟步的需求率，不是下一刻、平均耗电或剩余航时预测。P/Esc 暂停可查看待机、油门基数、进水附加、声纳、拖带/绞盘、水泵六分项和本航实际支出；暂停本身不耗电。结算保留该航实际分账，末步电量不足时只分摊真正扣除的电量。反馈只留在内存，新航次清零，重载不恢复这份账；不能把当前耗率当作一定能返港的保证。

## 任务怎么完成

- 沿雷达指示驶向琥珀色搜索海区；北方在雷达上方。搜索标记是公开的大致位置，并非舱体的精确位置。
- 船或已锁定舱超出海图范围时显示图外边缘方位提示；「图心」角度是从海图中心指向物体，北 0°、东 90°，不是船头朝向。港距／船距仍按真实世界坐标计算，图外两物体可能被截到同一像素，不代表重合或满足入港条件；任一端图外时不画普通实线拖缆。未锁定舱不因截边提示提前公开。
- 靠近海区后按 2 切「搜索」，减速至 5.5 m/s 以下并长按 E。声纳要求进入舱体 27 米范围；左侧显示规则、当前船速和锁定进度，不提前透露舱体精确距离。扫描完成后才会显示锁定目标。
- 靠近舱体至 15.5 米内，船速不高于 2.9 m/s、船舱相对速度不高于 4.2 m/s，按 Space 挂索。左侧会指明应继续靠近、降低船速还是稳住相对速度；看到「可按 Space 挂索」再尝试。阈值附近若显示 `>2.9` 等边界符号，表示真实读数已略超上限；以提示文字和当前规则为准。
- 声纳锁定后的 3D 圆环与标签跟随回收舱当前平面位置，不是固定在最初失联点；未挂索且距舱体严格小于 51 米时可见，超出范围后雷达仍保留空心锁定轨迹。挂索后圆环退场，以缆绳和带载返航提示为准。
- 按 3 切「稳索」返航。转弯提前收油，注意舱体会切弯，不能只看船是否避开礁圈。张力达到 100% 即进入过载，按提示松油门、减小转角；未到放缆上限时可按 F 放缆，必要时切 3 稳索。拖缆风险表显示的是累计断索风险，不是固定倒计时；张力降回额定范围后，风险也需继续回落至零。拖缆负载达到显示上限时读数为“≥150%”，实际张力可能更高。
- 缆绳上方标签 `OVERLOAD / RISK ACCUM` 表示当前过载及累计风险；`RISK FALLING` 表示当前张力已回到额定内、但累计风险仍在下降。普通 `MONITOR` 只是较高负载监控，不等于断缆倒计时；以实时 HUD 和正式结算为准。
- 船与舱**都进入青色港圈**，两者速度不高于 2.6 m/s、张力低于 68%，连续保持 1 秒才成功交付。临界读数可能以 `<2.6`、`>2.6`、`<68.0%` 或 `≥68.0%` 表示舍入方向；尤其张力必须严格低于 68%。按住 Shift 慢车、松油门可辅助稳住。
- 临港面板分别显示船舱是否进圈、两者速度、张力和实际稳定计时。绿色表示当前满足停泊条件，琥珀色表示仍有阻碍；提示保持稳定不代表已经交付，仍以连续 1 秒后的正式结算为准。
- 针礁水道的中央礁挡住直线航向；出港先向西侧留出余量，从中央礁西面绕行，返航同样给尾舱留足转弯空间。
- 碎潮回廊的断桅礁挡住直返路线。可以走贴近礁流的捷径，也可以绕开断桅礁、在宽水区转向。想走捷径时，先在不带载的出港途中熟悉横流；返程再决定是否让尾舱走这条紧弯。

| 1 / 2 / 3（任务台） | 选择「黑潮回收」/「针礁水道」/「碎潮回廊」 |
| X（任务台） | 远征 / 继续远征 |
| Tab / Enter（远征菜单） | 移动焦点 / 激活当前按钮 |
| Home / End / PgUp / PgDn（远征菜单） | 滚动长航图、报价、账本或复盘 |
| Enter | 快玩任务台开航、暂停/结算回任务台；远征激活当前焦点按钮 |

切出窗口会自动暂停。退出可使用菜单或窗口关闭按钮。快玩重开会放弃当前航程；远征正常关闭先暂停并确认按当前耗损救援，未入账结果另需确认。没有逐帧中途存档，不会重载后继续原位置驾驶。

结算可查看本航次用时、船/舱耐久损失、公开峰张，以及真实采集的扫描锁定、挂索、碰撞通知、过载和终态。复盘不是驾驶录像；碰撞通知不代表全部接触，建议也不是失败归因。复盘只在内存中保留，重开、返回任务台或切换合同清空。

## 本机成绩

只保存成功交付后的各任务最佳成绩：优先比较分数，同分取更短用时。失败、放弃和较差成绩不改写最佳记录。

Windows 默认位置：`%APPDATA%\StormlineBlackTide\stormline-best-contracts.json`。原两约继续使用该文件，碎潮回廊单独写入同目录的 `stormline-best-contracts.json.expansion.json`；旧版本仍可读取原两约。两个文件各自的 `.bak` 保存上一份已验证成绩，损坏文件可能保留为 `.corrupt-*`。程序目录与成绩目录分离，移动解压目录不应丢失成绩。

成绩是本机文件，不上传、不云同步；不要并行运行多个实例来写同一个档案。静音开关仅在本次运行内保留。若保存失败，结算会提示，不能视为已保存。

远征另存同目录的 `stormline-expedition-v1.json`，不读改快玩最佳。`.bak` 是上一份有效远征档；坏主档有合法备份时才可明确确认恢复并保留坏字节，无可用备份则禁止新建覆盖。可接受档案仍不得超过 98,304 字节；更大的坏主档仅在不超过 1,048,576 字节的独立保留容量内归档、读回并核对指纹后恢复，超过该容量拒绝恢复，不自动截断或覆盖。保留目标冲突或写失败也不覆盖坏主档；恢复含航行登记的备份仍按中断救援扣费，不免费恢复末帧。字节/修订冲突检查不是跨进程原子锁，不要同时写同一档案。
