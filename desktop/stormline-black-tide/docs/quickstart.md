# 风暴线：黑潮回收 / Stormline: Black Tide

v0.1.1 · Windows x64 本机验收候选 · 2026-11-20

## 启动

1. 将完整 ZIP 解压到一个可读目录。不要只从压缩包内打开 EXE。
2. 保持 `Stormline-Black-Tide.exe` 与 `Stormline-Black-Tide.pck` 在同一文件夹，然后双击 EXE。无需安装 Godot；无需登录或联网。
3. 默认进入任务台。先选「黑潮回收」熟悉拖带，再尝试「针礁水道」。按 1/2 选择合同，Enter 开航；也可使用鼠标菜单。

这是未经代码签名的本机候选构建。若系统阻止运行，先核对来源与 `SHA256SUMS.txt`；不要关闭防护软件或盲目绕过安全提示。静态核验确认 x64 GUI 可执行文件与完整 PCK；PCK 可由隔离无窗口探针校验资源加载，**当前版本未启动导出游戏 EXE**。首次图形启动、显卡兼容、中文字体、操控和音量仍未实测；旧版无窗口启动记录不代表此版本通过。

## 任务怎么完成

- 沿雷达指示驶向琥珀色搜索海区；北方在雷达上方。搜索标记是公开的大致位置，并非舱体的精确位置。
- 靠近海区后按 2 切「搜索」，减速至 5.5 m/s 以下并长按 E。声纳要求进入舱体 27 米范围；左侧显示规则、当前船速和锁定进度，不提前透露舱体精确距离。扫描完成后才会显示锁定目标。
- 靠近舱体至 15.5 米内，船速不高于 2.9 m/s、船舱相对速度不高于 4.2 m/s，按 Space 挂索。左侧会指明应继续靠近、降低船速还是稳住相对速度；看到「可按 Space 挂索」再尝试。显示数值有舍入，贴近阈值时应多留一点余量。
- 按 3 切「稳索」返航。转弯提前收油，注意舱体会切弯，不能只看船是否避开礁圈。张力达到 100% 即进入过载，按提示松油门、减小转角；未到放缆上限时可按 F 放缆，必要时切 3 稳索。拖缆风险表显示的是累计断索风险，不是固定倒计时；张力降回额定范围后，风险也需继续回落至零。拖缆负载达到显示上限时读数为“≥150%”，实际张力可能更高。
- 缆绳上方标签 `OVERLOAD / RISK ACCUM` 表示当前过载及累计风险；`RISK FALLING` 表示当前张力已回到额定内、但累计风险仍在下降。普通 `MONITOR` 只是较高负载监控，不等于断缆倒计时；以实时 HUD 和正式结算为准。
- 船与舱**都进入青色港圈**，两者速度不高于 2.6 m/s、张力低于 68%，连续保持 1 秒才成功交付。按住 Shift 慢车、松油门可辅助稳住。
- 临港面板分别显示船舱是否进圈、两者速度、张力和实际稳定计时。绿色表示当前满足停泊条件，琥珀色表示仍有阻碍；提示保持稳定不代表已经交付，仍以连续 1 秒后的正式结算为准。
- 针礁水道的中央礁挡住直线航向；出港先向西侧留出余量，从中央礁西面绕行，返航同样给尾舱留足转弯空间。

## 操作

| 按键 | 功能 |
|---|---|
| W/S 或 ↑/↓ | 前进 / 倒车 |
| A/D 或 ←/→ | 转向 |
| E（长按） | 扫描 |
| Space | 尝试挂索 |
| 1 / 2 / 3 | 推进 / 搜索 / 稳索功率分配 |
| Shift（按住） | 慢车辅助 |
| Q / F | 收缆 / 放缆 |
| P 或 Esc | 暂停 / 继续 |
| R | 重开当前任务 |
| M | 静音 / 取消静音 |
| 1 / 2（任务台） | 选择「黑潮回收」/「针礁水道」 |
| Enter | 任务台开航；暂停或结算时返回任务台 |

切出窗口会自动暂停。退出可使用菜单或窗口关闭按钮。重开和退出会放弃当前航程；首版没有中途存档。

## 本机成绩

只保存成功交付后的各任务最佳成绩：优先比较分数，同分取更短用时。失败、放弃和较差成绩不改写最佳记录。

Windows 默认位置：`%APPDATA%\StormlineBlackTide\stormline-best-contracts.json`。相邻 `.bak` 是上一个已验证成绩副本；损坏文件可能保留为 `.corrupt-*`，请不要随意删除。程序目录与成绩目录分离，移动解压目录不应丢失成绩。

成绩是本机文件，不上传、不云同步；不要并行运行多个实例来写同一个档案。静音开关仅在本次运行内保留。若保存失败，结算会提示，不能视为已保存。

## 首版范围与排障

- 两个独立任务，程序化 3D 场景、雷达、驾驶 HUD、惯性拖带和合成音效；不是六自由度船体，也不模拟缆绳绕礁。
- 面向 Windows x64、键盘和鼠标；未实现手柄、联网、成就、云存档或安装器。
- 画面使用 Compatibility 渲染路径，中文优先使用系统微软雅黑等字体。尚未测定最低硬件和帧率，不承诺特定设备性能。
- 遇到问题请保留场景截图（由你自行截取）、显卡型号、Windows 版本及 `%APPDATA%\StormlineBlackTide\logs\godot.log`（若已生成）。分享日志前检查是否含本机用户名等个人信息。
- `ACCEPTANCE.md` 列出尚需真人执行的验收；`BUILD-MANIFEST.json` 和 `SHA256SUMS.txt` 记录构建证据与文件校验。
