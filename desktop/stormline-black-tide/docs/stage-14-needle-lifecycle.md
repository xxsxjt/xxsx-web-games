# 阶段 14：自然受损航次的暂停/失焦与重开

日期：2026-11-20。仅新增 `tests/needle_lifecycle_test.gd`、完整 QA 注册和文档；复用阶段 13 纯输入驾驶器，不改生产模型、正式合同、界面、音效、成绩或输入规则。

## 航次与对照

- 每次从正式针礁合同自然开局，经正常控制扫描、挂索，实际驶入中央针礁；读取真实损伤和命名碰撞事件后才插入生命周期操作，不摆放临港夹具、不注入位置/资源/天气或报告。
- 先运行恢复返港、持续过载两条不中断应用基线。每条应用航次均有独立初始化的模型和独立驾驶器，以相同输入序列逐 tick 比较公开快照、合同内容、碰撞冷却、提示时钟和危险标志；隐藏字段只读，不修改。
- 基线与生命周期航次均在开局首 tick 和碰撞后首 tick 使用正式应用 `_physics_process()` 的中立轮询输入，其余航行使用共享 `_advance_simulation()` 边界。这不是全程真实键盘输入；主要验证生命周期接线和未消费 Space 队列。
- 每档在触礁后先用合成 Space 排队，再经 P 或直接失焦回调暂停。重复失焦、暂停时 Space/1/2/3，以及 1/60、0.75、60 秒的模拟/物理/呈现回调均不得改变公开状态、碰撞时钟或驾驶器 tick，也不得写分数。

| 暂停入口 | 后续操作 | 对照要求 |
|---|---|---|
| 合成 P / 失焦回调 | Esc 恢复并绕礁返港 | 无补算，恢复首个轮询 tick 保持挂索；完整结果与不中断恢复基线一致 |
| 合成 P / 失焦回调 | Esc 恢复后持续过载 | 真实断缆，无成功报告或成绩覆盖；与不中断过载基线一致 |
| 合成 P / 失焦回调 | R 重开 | 清空旧损伤/时钟/挂索/输入，从正式开局再完成整条受损返港航次 |
| 合成 P / 失焦回调 | Enter 回任务台，再 Enter 开航 | 放弃受损航次不记分；重新开航及交付与恢复基线一致 |

共两条不中断基线、八档生命周期操作；四档重开/回任务台先放弃一段真实受损航次，再重新完整驾驶。每条完成航次在 debrief 后再尝试失焦和大 delta，验证终态与成绩不重放。隔离成绩目录为本项目 `.testdata/needle-lifecycle-*`，测试结束仅清理当次目录，不访问玩家档案。
