- [ ] 任务台按 1/2/3 选约、Enter 开航、鼠标菜单、暂停/继续、重开和退出均正常。进入航次后 1/2/3 只切换功率。

## 雷达截边的范围与方位（阶段 31，真人未验）

- [ ] 拖船或已允许显示的回收舱超出海图范围时，边缘标记／提示明确是图外方位而非实际位置；方位与从海图原点指向真实世界位置的方向一致，且能区分拖船航向与图外方位。不同距离被截到同一边缘不能被误读为等距或重合。
- [ ] 港距、已公开的舱距等数值仍来自未钳制的真实世界坐标，不由截边后的像素反推；两物体均截边时，连线或标记不会暗示已接近、真实缆长为零或已满足入港条件。回到图内后恢复按米制比例显示；调整窗口不改变模拟位置或规则。
- [ ] 未锁定时，图外提示同样不泄露回收舱的精确位置、距离或方位；搜索区、A/B 测站与已锁定舱体的含义可辨。锁定后的视距外迹线与海图范围外截边可区分，不把任一种边缘／空心标记误读为真实位置或已在视距内。

## 完成黑潮回收

- [ ] 能理解琥珀色搜索区和青色港圈的区别；低速长按 E 可完成扫描。
- [ ] 未扫描、过远或过快时拒绝挂索，并提示原因；条件满足时 Space 能挂索。
- [ ] 扫描显示当前船速/进度，未锁定时不泄露舱体精确距离；未完成扫描不显示 100%。锁定后挂索指引区分距离、船速、相对速度阻碍，阈值附近通过边界符号说明舍入方向，不误报可挂索。
- [ ] 1/2/3、Shift、Q/F 的效果可感知；转向和倒车可控，不必靠自动驾驶才能通关。
- [ ] 船先入港但舱仍在外面时不会结算；船舱都进圈、低速稳索 1 秒后成功。
- [ ] 临港速度、张力、绿色/琥珀色及稳定计时与实际操作相符；阈值附近的舍入方向可辨，且张力严格低于 68% 才可停泊。完整提示、事件通知和危险警告同时出现时不相互遮挡。无窗口四分辨率检查不代替本项中文字体与画面验收。

- [ ] 回港后理解排干与临封不修结构，带破口再出航重新进水；维修资金、材料和压力代价可接受。

### H 封堵阻碍与逐包触发（阶段 31，真人未验）

- [ ] 无预装包、没有未临封破口、船速 ≥2.2 m/s、油门绝对值 >0.05、缆张 ≥68% 时，反馈能说明当前阻碍，不把单纯 0% 进度或固定门槛说明当作已解释原因；多个阻碍并存时也不虚报可施工。触礁仍以碰撞通知和工作清零反馈，不把派生条件提示当作未公开的逐 tick 接触／重触发状态。边界附近的显示舍入不误导玩家认为严格门槛已满足。
- [ ] 满足门槛后按住 H 连续五秒才完成一包；松键、超速、油门／张力超限或触礁会清零本次工作，未完成不耗包，反馈与实际进度一致。临封不被误读为恢复船体或永久修好结构。
- [ ] 完成每一包后，即使仍有开放破口与剩余包，持续按住 H 也不继续施工或连耗下一包，并明确提示须松开 H 再按；松开并重新按住后，下一包才重新累计完整五秒。没有剩余包或已无开放破口时显示对应阻碍，不误报只需重按就能施工。
