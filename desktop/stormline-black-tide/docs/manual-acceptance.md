# v0.1.1 桌面人工验收单

**状态：以下项目均未执行。** Agent 仅做无窗口回归、PCM 数据检查、导出和静态文件核验，没有启动游戏窗口、播放声音或做 GUI 自动化。

请从完整解压目录启动 `Stormline-Black-Tide.exe`，记录测试日期、Windows/显卡、分辨率和构建校验值。先降低扬声器音量再开始；每项按实际观察勾选。

## 启动与界面

- [ ] 不依赖 Godot 编辑器或联网即可启动；默认任务台出现，无崩溃/空白窗口。
- [ ] 1280×800 和自用分辨率下中文可读，菜单、HUD、雷达和按键说明不遮挡关键区域。
- [ ] 调整窗口大小后物体世界尺寸与速度不变，界面仍可操作。
- [ ] 拖船、海面、礁石、目标与港圈完整可见，没有反面丢失、闪烁或穿帮；跟随镜头能同时观察船和尾舱。
- [ ] 任务台按 1/2 选约、Enter 开航、鼠标菜单、暂停/继续、重开和退出均正常。
- [ ] 暂停摘要、航行提示/通知、海图与世界位置一致；成功/断缆结算第一帧显示对应航线、结果、统计及纪录状态，重开/回任务台/换约没有可见的旧提示或目标残留。无窗口切屏测试不替代实际画面与鼠标操作验收。
- [ ] 切出窗口后游戏暂停且静音；切回后仍暂停，继续时不会跳过航程。

## 完成黑潮回收

- [ ] 能理解琥珀色搜索区和青色港圈的区别；低速长按 E 可完成扫描。
- [ ] 未扫描、过远或过快时拒绝挂索，并提示原因；条件满足时 Space 能挂索。
- [ ] 扫描显示当前船速/进度，未锁定时不泄露舱体精确距离；未完成扫描不显示 100%。锁定后挂索指引区分距离、船速、相对速度阻碍，阈值附近通过边界符号说明舍入方向，不误报可挂索。
- [ ] 1/2/3、Shift、Q/F 的效果可感知；转向和倒车可控，不必靠自动驾驶才能通关。
- [ ] 船先入港但舱仍在外面时不会结算；船舱都进圈、低速稳索 1 秒后成功。
- [ ] 临港速度、张力、绿色/琥珀色及稳定计时与实际操作相符；阈值附近的舍入方向可辨，且张力严格低于 68% 才可停泊。完整提示、事件通知和危险警告同时出现时不相互遮挡。无窗口四分辨率检查不代替本项中文字体与画面验收。
- [ ] 成功结算有分数和本机最佳提示，关闭游戏后再次启动仍可见最佳成绩。
- [ ] 重开、暂停回任务台和较差成绩不会覆盖已有最佳。

## 针礁水道与失败

- [ ] 第二个任务确实更换港口、目标和礁流布局，不沿用第一个任务的场景或 HUD。
- [ ] 能以手动操作绕过中央针礁并带舱返航；到港速度要求存在合理操作余量。
- [ ] 持续大油门、收缆造成过载时，预警后确实断缆并显示失败；失败不产生最佳记录。
- [ ] 拖缆仪表在额定 100% 处清楚区分过载与额定内；过载行动提示只建议可用操作，风险表在卸载后显示回落直至清零。碰撞通知和低电量警告不被旧过载事件覆盖；≥150% 表示读数封顶，不被误读为精确载荷或倒计时。
- [ ] 声纳锁定前目标标记与回收舱不提前出现；锁定且进入公开显示范围后目标标记/舱体显现，超过范围后隐藏；暂停、断缆、重开与换任务后没有旧合同的场景标记残留。headless 节点检查不替代实际镜头下的可读性验收。
- [ ] 缆绳的场景标签可读，能区分实时过载、风险回落与普通监控，并与 HUD 相符；卸载、断缆、重开和切换任务后没有旧标签残留。无窗口节点检查不替代真实 3D/字体/镜头验收。
- [ ] 撞礁、窗口到期等失败有清晰原因，失败后可重开或回任务台。
- [ ] 受损并消耗部分电量后仍可控地脱离礁区；若船体、回收舱或电量接近耗尽，失败原因清晰且不会伪造成功成绩。模型层复合压力回归见 `docs/stage-09-compound-risk-recovery.md`，不替代本项实际桌面操作。

## 声音与稳定性

- [ ] 发动机随油门/航速变化，风浪声与风暴强弱相符，不刺耳、不爆音或卡顿。
- [ ] 扫描、挂索、预警、断索和到港提示有区别；接近过载时警报及时可听。
- [ ] M 静音、暂停、任务台和失焦停止声音，恢复后不会补播旧事件；结算音能听完整。
- [ ] 连续切换两条任务、重开和退出再启动，没有旧拖缆残留、异常内存增长或崩溃。
- [ ] 自用设备的流畅度可接受，记录分辨率、显卡与体感/实测帧率；当前没有最低配置或 60 FPS 承诺。

## 已知需要重点观察的余量

自动航行的黑潮交付时舱体距港边仅约 0.74 米；针礁交付保持段舱速峰值四舍五入为 2.60 m/s，接近 2.6 限值。这证明指定输入可达成规则，不证明真人操作余量充足。若持续出现临门失败，应记录路径和 HUD，而不是直接认定已通过平衡验收。
