# v0.1.0 开发与验收

更新：2026-11-20。状态：**Windows x64 本机首版候选已生成、无窗口回归通过，真实桌面验收尚未执行；未对外发布。**

**方向。** 本作独立使用 Godot 4.3 Compatibility。核心是驾驶与带载决策，不是解谜；不接入网页总站。

**闭环。** 任务台选约 → 找到搜索海区并锁定漂流舱 → 低相对速度挂索 → 选返航路线与功率、管理缆长 → 船和舱在港内同时停稳 → 结算并比较本机记录。搁浅磨损、失去动力、回收舱破损、断索或风暴窗口到期均可失败；重开不污染最佳成绩。

**两份任务。** 黑潮-01 是宽航道入门；针礁航道把较小的交付区、近礁侧风、水流和更重的舱结合在一起。二者共享规则，不只是换色。首版采用平面动力学配 3D 画面，不模拟六自由度船体或缆绳绕礁。

**模块边界。** `src/storm_sim.gd` 持有任务规则与 60 Hz 模型；`src/storm_world.gd` 和 `src/storm_hud.gd` 只消费同一份公开快照；`src/storm_audio.gd` 预先合成有界 PCM 循环与事件提示音，按快照控制播放；`src/storm_records.gd` 仅保存成功任务最佳成绩；`src/main.gd` 将桌面输入、暂停/开航、3D、HUD 和保存连接起来。引擎配置将 `user://` 定向到独立的 `StormlineBlackTide` 用户目录。

**当前控制。** W/S 或方向键推进/倒车，A/D 转向，长按 E 扫描，Space 挂索；1/2/3 切换功率，Shift 慢车，Q/F 收放缆，P/Esc 暂停或继续，R 重开，M 静音。菜单 Enter 开航，暂停/结算 Enter 返回任务选择。

## 阶段 02：界面几何与键盘适配器（2026-11-20）

对 1440×900、1280×720、960×600、1920×1080 和任务台/驾驶/挂索返航/暂停/失败/成功六个状态新增程序化 HUD 几何检查。测试先发现 14 个失败：1280×720 面板交叠、960×600 菜单按钮越界及小窗口下仪表面板交叠。`storm_hud.gd` 新增 1440×900 逻辑画布比例适配，低分辨率依比率缩放，不改模拟和世界坐标。修复后 232 项全通过；检查覆盖控件矩形，不等于图像渲染/鼠标实测。
