# 独立桌面游戏源码

本目录中的游戏独立构建，不是网页站点的浏览器入口，不使用网页作品的存档键，也不进入根目录 npm 构建产物。

## Stormline: Black Tide / 风暴线：黑潮回收

目录：`stormline-black-tide/`。

Godot 4.3 Compatibility，Windows x64。两份合同要求驾驶拖船搜索、扫描、挂索并将回收舱低速拖回港口，只有成功交付才保存本机最佳。

源码、隔离测试、构建工具和开发记录随阶段更新；官方模板、缓存、玩家档案和 Windows 二进制不放入 Git。入口说明及验证边界见项目 README。

阶段完成标准：针对性测试与回归 → 正常 Git 提交/推送 → 远端分支和文件树回读，逐文件 Git blob 核验。没有外部发布步骤时不声称已发行二进制或部署网页。
