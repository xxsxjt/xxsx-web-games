# 静态网页游戏总站迁移计划

总站作为 xxsx 全部静态网页游戏的统一入口；每款游戏可以独立发展。现有舰站集合只是第一批内容，新作品无需使用霓虹科幻题材或共享档案。

## 当前状态

V50 完整源码作为初始内容导入。现有页面、路由、素材和存档规则保留。以下结构迁移尚未实施，不能将仓库导入等同于总站首页重构。

## 推荐实施顺序

1. 增加独立的总站首页与游戏目录，提供类型、操作方式、单局时长、存档方式和直接开始入口；旧链接继续可用。
2. 将现有舰站集合放进独立游戏目录，并用目录清单登记每款游戏，统一维护标题、简介、封面和入口。
3. 让新作品进入独立路径，例如 `games/<slug>/`。每款游戏管理自己的代码、素材和带命名空间的本机存档。
4. 按实际重复需求抽取通用输入、音量、全屏和存储辅助；不提前强制所有游戏使用同一引擎或统一成长系统。
5. 总站只负责发现游戏、收藏和最近游玩等通用体验；跨游戏奖励和世界观由具体系列自行选择。

## 迁移验收

- 手机和桌面均能从总站直接进入各游戏，退出时能回到目录。
- 旧 hash 入口继续指向正确页面。
- 原存档可恢复，清除或重置某款游戏不会影响其他独立游戏。
- 未进入的游戏无需加载完整玩法模块和全部素材。
- 构建结果保持静态托管兼容，发布与 GitHub 同步均有核验记录。
