验收重点：玩家十秒内完成第一次寄壳；同房间有两条不同顺序的可行路线；失败能归因于位置、冷却或壳的限制；不依赖永久属性、抽卡或每日任务强行留存。完整候选与矩阵见 [new-game-concepts-v55.md](new-game-concepts-v55.md)。
