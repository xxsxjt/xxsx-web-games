# v37：游戏路由与站点内容隔离

## 审查结论

v36 的“独立游戏”只完成了玩法规则和入口卡片的区分。运行时仍把游戏大厅覆盖在原战斗舞台上，另外四款游戏也位于舰桥 DOM、沿用舰桥导航与站点外壳，因此实际体验仍像一个主游戏下的附属模式。本版按结构修正，不再把卡片数量视为独立性的证明。

## 目标结构

- `#arcade`：站点默认入口，只负责游戏目录、共享档案摘要和公告入口。
- `#game/expedition`、`#game/relay`、`#game/lab`、`#game/salvage`、`#game/blackbox`：五个可直接打开、可刷新恢复的游戏页。
- `#station/<view>`：舰桥、机库、星图、资料库、攻略、构筑台、协议、挑战、日志和公告等站点内容。
- 远征战斗复用成熟战斗引擎，但使用自己的开场/规则页；其他四款游戏在 DOM 和显示层都位于舰桥之外。

## 共享边界

各游戏的规则、计时器、分数和结算仍分别运行。共享本机档案负责记录跨游戏奖励、挑战、蓝图与日志，不提供通往其他游戏的站内侧栏。离开游戏页时必须停止该模式计时器；离开远征战斗时取消动画循环，不发放未结算奖励。

## 路由验收

- 从大厅进入每款游戏时只显示所选游戏页；不显示其他游戏页、战斗 HUD 或舰桥侧栏。
- 游戏目录、站点内容、公告分别有明确返回路径；任务板动态生成的活动入口也能跳到独立游戏页。
- `#game/<id>` 与 `#station/<view>` 可直接加载和刷新；浏览器前进/后退切换路由时重新建立对应页面。
- 切换游戏会清除其他模式计时器；离开正在运行的射击局会取消 RAF，并清理暂停/结算弹窗。
- 保持站点公告悬浮窗、各玩法独立纪录和既有本机档案迁移。
