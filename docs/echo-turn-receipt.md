# 回声实验室：结束回合结算回执

XXSXEchoDeck.endTurn 在原有 message 中追加该次真实结算摘要，不增添存档字段、日志历史或第二个界面区域。每次实际执行的敌方攻击逐击列出敌人、护盾实际吸收量与本次实际生命损失；污染单独列出本轮实际结算伤害和结算后的剩余层数；胜利结算的自修复晶体若实际回复生命，也会显示回复量。回执末尾记录从 endTurn 调用前到本轮结算完成后的生命净变化，因此可能包含实际回复。

死亡时保留“实验失败”的原因，并只记录死亡前实际发生的攻击；生命归零后未执行的后续连击与敌人不会出现在回执里。消息仍使用既有 message 字段，限制在 500 字符内。缺少可选 reserve 字段的合法 V53 旧进行中状态不受影响，结束回合后继续使用常规状态结构。

定向无窗口验证：node tests/echo-receipt.cjs；既有战役回归：node tests/campaign-games.cjs。模拟测试验证文本与实际状态差值，不证明窄屏的实际换行/操作区可见性；本任务未运行浏览器或游戏客户端，也未做真人试玩。
