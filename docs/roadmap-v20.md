# Neon Drift / 大型扩展路线

## v21 已交付：星图与种子化远征

- 航线页从静态五节点条升级为五段分岔星图；四条星区航线各自使用同一枚 `runSeed` 生成可复盘节点组合。
- 每段可在出击前重新规划节点。交战、回收、信号、精英、修复、异常和 Boss 节点拥有不同的风险 / 奖励修饰，并在战斗中生效。
- 远征日志记录种子与路线计划；结束一局后自动生成下一枚待出击种子，也可以在航线页主动重掷。
- `src/core.js` 新增纯函数 `hashSeed`、`createRng` 和 `generateStarMap`，确定性部分与战斗运行时随机性分离。
- 82 项回归、静态构建、桌面浏览器和 390 / 320 / 横屏视口检查通过；真实 Android、iOS、Safari 与长期平衡性仍属于未验证边界。

## v20 已交付：内容站点层

- 舰桥新增世界观资料库、指挥官攻略、构筑实验台和站点动态四个一级页面。
- 资料库包含 9 条世界 / 星区 / 势力 / 系统档案，攻略包含 8 篇入门、构筑、Boss、短局、局外和航线笔记，均由本机版本化数据渲染。
- 构筑实验台调用与实战相同的 `src/core.js` 构筑计算，支持机体、四槽装备、稀有度、等级和联动预览；保存只复制到预设，不修改当前实战装备。
- 舰桥增加站点目录与最新动态摘要，内容入口和四条活动线共享同一套离线档案。
- 80 项回归测试、静态校验和浏览器桌面 / 内容页自审通过；真实 Android、iOS、Safari 与长期平衡性仍属于未验证边界。

v20 已把站点从“指挥台 + 三种短局 + 主战斗”扩成可持续阅读和研究的本机内容站点。下一阶段仍以公开、无登录、手机优先为前提，按下面顺序扩展，不牺牲当前能直接打开和游玩的特性。

## 1. 指挥台世界层

- 将任务板升级为“星区航图”：每次远征完成后生成 5 个节点，节点类型为战斗、事件、商店、打捞、Boss。
- 节点使用同一份 `runSeed`，让航线选择、掉落和短局事件可复盘，而不是只改变文案。
- 为每个星区提供独立的背景图、环境色、敌人池和 Boss 组合；先复用现有 atlas，再逐步补充新素材。
- 在日志中增加“构筑快照”和“路线快照”，让玩家能回看为什么赢或输。

## 2. 构筑与战斗深度

- 增加三类可叠加的局内遗物：改变射击形态、移动风险和资源经济；遗物只影响当前远征，避免局外数值无限膨胀。
- 给每种机体增加一个主动技能和一个代价明确的被动分支，保持“爆发 / 防御 / 机动”三种决策语言。
- 将现有四槽装备、联动和 Boss 破盾窗口接入同一套比较面板，所有预览继续调用 `src/core.js` 的纯函数。
- 为后期波次加入“精英编队”和 Boss 变体，但先以模拟测试锁住投射物上限、伤害上限和低帧率行为。

## 3. 站点活动层

- Signal Relay：加入路线干扰和连击风险，让高分来自选择而不只是点击速度。
- Echo Lab：加入每日固定种子（仍只保存在本机），便于玩家比较自己的成绩。
- Salvage Run：增加“带回 / 继续深入 / 立即撤离”的三段式风险选择，缓存奖励与热度曲线联动。
- 未来可以新增一个不依赖战斗的“舰桥交易台”或“编队调度”模式；每个模式必须有独立完成条件、独立日志类型和可重复的短局入口。

## 4. 数据与发布边界

- 当前 v19 继续使用 `localStorage`：预设、短局成绩和日志是明确的设备本地档案。
- 只有在需要跨设备同步、公开排行榜或多人挑战时，才引入 D1/服务端；届时先定义 schema、迁移、匿名标识和隐私说明，再接入 UI。
- 每个新模式必须通过四道门：纯逻辑回归、静态 DOM/资源检查、390/320/横屏 iframe、公开 URL 冒烟。
- 发布包始终由 `dist/` 生成并与源文件逐字节校验；任何线上版本都绑定可追溯的 git commit。

## 5. 体验与美术质量门槛

- 触控目标保持至少 44px，窄屏导航使用可横向滚动的 rail，不把桌面九宫格硬挤进手机。
- 所有动态扫描、漂浮和闪烁效果提供 reduced-motion 降级；状态文本使用 `aria-live`，不依赖颜色传达唯一信息。
- 新增素材优先透明 atlas / 场景层 / HUD 叠加三层组合，避免“单张贴图铺满页面”；每个模式至少有一套独立色彩语义。
- 每次扩展后都保留“已验证 / 未验证”清单：云端 Chrome 不代替真实 Android、iOS、Safari 和长时间平衡性试玩。
