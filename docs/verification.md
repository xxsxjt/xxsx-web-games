# 重构验证记录

日期：2026-09-16。目标：Neon Drift v21 星图扩展，在 v20 内容站点、v19 指挥台、深空打捞和构筑预设基础上，把航线变成可复盘的确定性远征计划。

## 自动化结果

- `node scripts/build.mjs`：成功；仅生成 HTML、四个源码模块/样式和四张 WebP。
- `node tests/core.cjs`：15 项通过。固定时钟在 5、10、15、30、60、120 FPS 输入下均推进准确的 4.5 秒；验证升级中断、指针所有权、瞬闪方向和边界，以及相同种子生成相同星图、不同种子生成不同星图。
- `node tests/regression.cjs`：82 项通过。除既有战斗/构筑回归外，新增打捞格网邻接、一次性奖励、撤离结算、日志写入、构筑预设往返、资料筛选、实验台不污染实战构筑、种子路线规划、节点修饰进入远征和动态时间线验证。
- `node tests/static-validation.cjs`：通过；验证模块加载顺序、语法、DOM ID、发布文件逐字节一致、资源存在、测试页未打包和响应式样式。
- `git diff --check`：通过。

## 证据边界

窄屏和横屏使用真实尺寸的同源 iframe，验证的是 Chrome 排版和鼠标交互，不是 Android/iOS 真机、Safari 或硬件多点触控。多指输入、低帧率与 Boss 后期机制主要由模拟测试覆盖。五分钟模拟包含无敌保护，不能作为正常玩家生存率或长期平衡性的结论。

页面日志检查未发现站点脚本错误；浏览器扩展自身的日志单独排除。公开访问范围和部署结果通过 Sites 服务确认；公开地址已完成内容入口、星图、构筑实验台和动态时间线冒烟，短局与日志沿用上一版本已验证的本机流程。
