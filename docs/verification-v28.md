# Neon Drift v28 验证记录

日期：2026-09-20。本轮针对“公告入口分散、站点模块互不回写、主武器掉落重复且替换价值低、功能实现边界不清晰”完成一次系统联动改造。

## 已完成

- 站点动态统一渲染为公告浮窗；顶部公告按钮、舰桥动态入口和站点目录中的动态卡片打开同一份公告数据。
- 装备扩展为五槽：主武器、副武器、核心、战术、推进。主武器继续决定主要射击流派，追猎导弹舱和裂阵散射舱提供独立的副武器火力。
- 副武器使用独立冷却和弹道，理论面板与战斗 HUD 的 DPS 都包含副武器贡献；导弹牵引、裂阵漂移两组联动已接入共享构筑计算。
- 重复装备在装备栏或背包中自动融合，等级最高到 Lv.6，满级后继续用更高稀有度提升；战利品选择降低连续主武器刷新的概率，并限制同一轮的主武器重复。
- 旧四槽本机存档会自动补入默认副武器，三套预设和构筑实验台沿用五槽格式。
- 信号中继和回声实验室完成后都会带回星尘、写入编年史，并刷新舰桥、协议和任务板相关展示；远征和深空打捞原有奖励链继续保留。
