# V41：边境战术战役与站点总体计划

## 站点目标

维护《霓虹》公开游戏站点：让两款完整主线和四种小游戏各自有清楚的规则、完整的开局与结算，再由舰站档案连接成长、委托、攻略和版本记录。站点继续使用静态托管和本机存储，不因新模式自动引入登录、云同步或第三方后端。

## 当前产品地图

| 区域 | 责任 | 入口 |
|---|---|---|
| 新伊甸游戏厅 | 游戏选择、共享档案摘要、公告 | `#arcade` |
| 霓虹突围 | 实时射击、局内装备、航线远征 | `#game/expedition` |
| 边境战术：失落站 | 三人小队回合战、档案续玩 | `#game/border` |
| 小游戏合集 | 中继、实验室、打捞、黑盒 | 各自 `#game/<id>` 路由 |
| 舰站 | 机库、航线、图鉴、攻略、构筑、协议、委托、作战日志、动态 | `#station/<view>` |

模式规则和纪录彼此独立；星尘、情报、模块、研究、跨游戏委托和作战日志进入同一份本机指挥官档案。

## V41 交付范围

- 独立的 `#game/border` 游戏页、合同选择、小队状态、7×7 棋盘、敌方预警、掩体、技能、终端目标、补给选择和最终撤离。
- 每个移动、攻击、技能、互动、回合和舱段选择之后写入断点存档。
- 主档、待提交档、有效备份和隔离的坏档有校验与读回验证；读取时选择修订号最新的有效记录。无法安全保留坏档时，不开始新行动。
- 结算以行动编号去重，再接入共享资源、任务板委托、指挥官档案和编年史。
- 旧站点档案迁移到 schema 11；增加新手攻略、任务目标和 V41 动态说明。

## 不可破坏的体验约束

1. 旧档案升级保留已有成绩、装备、资源、委托和历史。
2. 不将失落站战术改成射击模式的皮肤；其行动点、位置、预警与撤离是独立机制。
3. 返回游戏目录、进入舰站或刷新时，活动行动仍可恢复；结算不能重复给奖。
4. 坏档、空档或局部写入失败都不能悄悄覆盖上一份有效副本。
5. 320px 窄屏可操作；棋盘触控目标不溢出页面，焦点可见，尊重减少动态效果设置。
6. 静态发布包必须与源码一致，所有直接路由都能从页面刷新后重新进入。
