# V61 · 界门交易行

V61 在游戏厅迷你游戏区加入《界门交易行》入口，并将该路由直接导航至独立经营页。旧地址、收藏/最近打开 ID 映射及旧本机存档键继续兼容。

本地访客现在明确保存世界 ID、名称、标记和主题色。启动时会将旧访客的数字世界编号映射回六类原角色来源，并把补全后的访客写回同一档案；欢迎和访客公告只替换对应旧条目，保留成交、行情、维护费和拍卖等结算记录。十一界市场旅行、未实现界域及完整跨界贸易均未接入。
