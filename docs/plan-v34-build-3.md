# Neon Drift v34：可见联动与战斗行为自审计划

日期：2026-09-22

## 这一轮要解决什么

v33 已经把短局成绩接入蓝图、把五槽装备接入实验台，但玩家仍需要自己猜测“短局究竟会解锁什么”。同时，主武器分支虽然有标签和说明，电弧的额外跳跃没有完整反映到运行时。

v34 的目标是把这两条联动变成可观察、可验证的闭环：

`短局进度 → 蓝图进度卡 → 副武器掉落池 → 实验台测试 → 战斗行为反馈`

## 实施项

### P0：蓝图进度可见

- 构筑实验台显示猎蜂无人机、光栅切割器、尾迹雷舱三张蓝图卡。
- 卡片展示来源、累计进度、解锁状态和“前往对应短局”入口。
- 已解锁蓝图明确显示“已装入掉落池 / 可在副武器槽测试”。
- 舰桥内容入口把蓝图数量纳入站点状态摘要。

### P1：分支行为真实化

- 主炮和光栅弹携带剩余链式跳跃次数。
- 导流节点与雷暴分流每次跳跃只选择未命中的近邻目标。
- 连锁伤害逐跳衰减，避免固定伤害重复复制。
- 旧的单跳行为保持兼容，分支只是增加连续跳数。

### P2：存档与公告

- 启动时根据已有短局累计数据自动同步已达标蓝图，兼容 v33 及更早档案。
- 站点动态作为公告悬浮窗的最新条目，记录本轮联动和验证范围。

## 验收标准

- 新档案的构筑实验台能看到三张锁定蓝图及进度条。
- 已达标的旧档案刷新后蓝图自动进入掉落池，不需要再完成一次短局。
- 点击锁定蓝图能跳转到对应短局；解锁后卡片状态和掉落池状态一致。
- 电弧基础链、导流节点和雷暴分流的跳数分别可被回归测试观测。
- 构建、核心测试、回归测试和静态检查通过。
- 公共站点验证公告、实验台、星图、战斗启动和控制台应用错误为零。
