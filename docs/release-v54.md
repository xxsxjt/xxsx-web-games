# V54：决策预估、回合蓄能与塔防反馈

日期：2026-10-09。基线：V53；GitHub 基线提交 `3eee6a678b3827a4996ee198661b74358a3c8435`。沿用六张 V52 游戏图标及现有站点设计。

## 玩家可见变化

| 游戏 | 行为与选择 |
| --- | --- |
| 回声实验室 | 敌情和目标移到手牌之前。卡牌显示当前目标实际破盾、生命伤害、标记、护盾、聚焦和抽牌预估；直接结束显示结算后的生命。新增「蓄能结束」：敌人照常行动，最多两点未用能量留到下一回合，战斗之间不累积。击破所选目标后自动选中存活敌人，满血不能付费修复。 |
| 深空打捞 | 可规划气闸、撤离、未用氧气或工具仓；高亮当前可通行的最短路线，按货物重量、热度、沿途一次性氧气补给预估氧气与护甲。规划不自动移动，未解除守卫不能穿过。前两层组件仓与第三层核心仓名称区分。 |
| 信号中继 | 显示待入场数量、下一次入场时间和击破数；塔的射线、爆破范围和命中数字来自实际结算。可点地图炮位选择，保留下方六个可键盘操作的按钮。暂停时干扰消灭最后一个敌人也会立刻清波结算，移除已击破残影且不重复奖励。 |

手牌在 320px 普通字号下排两列，200% 根字号下排一列；结束操作条随滚动保持可用。塔防尊重减少动态效果偏好，不显示瞬时射线和数字。修复同页切换游戏后浏览器标题没有跟随入口的问题。「关于」中的 GitHub 总仓库入口继续保留。

## 存档与兼容

沿用 `xxsxSalvageExpeditionV1`、`xxsxEchoDeckV1`、`xxsxRelayDefenseV1`。V53 没有 `planGoal` 或 `reserve` 的档案仍可读取。旧短局、射击、战术和解谜的原入口与档案键保留。

每次写入之前比较当前主档与本页加载/上次写入时的原始字节：如果其他页面已经修改主档，本页停止写入并提示刷新读取新进度，主档及备份不被替换。旧页面仍可在内存中操作，但这些操作不会写入冲突档案。这不是原子事务、跨页面锁或自动合并；极端同时读写仍不在保证范围内。坏档保留、有效备份恢复和待写验证沿用 V53。塔防隐藏且已暂停时不再重复写入；运行中的后台切换仍暂停保存，刷新后暂停恢复，不补算离线时间。

构建保留 V51、V52、V53 已发布哈希 URL 和原地址别名，同版本的未发布中间哈希不累积。没有新增第三方运行依赖、账号或后端。
