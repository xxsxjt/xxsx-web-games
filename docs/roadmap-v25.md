# Neon Drift v25–v26 现状与安排

日期：2026-09-18。本文把 v24 基线审查、v25 本轮落地内容和下一阶段安排放在同一处，供后续迭代与验收使用。

## 当前判断

Neon Drift 已经是一个公开、免登录、离线优先的内容站点，包含舰桥、主线远征、星图航线、机库构筑、图鉴、协议、挑战、信号中继、深空打捞、回声实验室、作战日志、世界观、攻略、构筑实验台和版本动态。

当前最有价值的工作已经从“再加一个入口”转向两件事：让主战斗更容易读懂，让不同模式切换得更可靠。

| 区域 | 现状 | 风险 | 处理方向 |
|---|---|---|---|
| 内容站点 | 内容入口完整，资料与玩法互相链接 | 页面继续增加会放大导航和生命周期耦合 | 先保持舰桥为唯一总入口，新增内容必须有真实玩法或日志回写 |
| 主战斗 | 已有独立敌机图集、场景图、冲击环和战斗引导 | 敌方攻击仍可能在密集弹幕中被忽略，Boss 机制需要更清晰的节奏 | 增加攻击前摇、目标标记、伤害层级和破盾窗口反馈 |
| 模式运行时 | 远征由主循环驱动，三个短局各有计时器 | 切换入口时如果遗漏清理，可能出现后台偷跑 | 逐步使用统一运行时边界，并为每个模式保留退出验收 |
| 存档 | 当前浏览器 `localStorage`，无需账号即可使用 | 没有跨设备同步和真实排行榜 | 在核心体验稳定前不引入登录和云端服务 |
| 资源 | v3 敌机图集和独立航线背景已进入发布包 | 仍有一个未被当前代码引用的工作区 Boss PNG 资产 | 保留未提交资产，不让它影响当前构建；确认美术方向后再替换 Boss 资源 |

## 本轮已落地

- 新增 `src/runtime.js`，为信号中继、回声实验室和深空打捞提供可追踪的计时器集合。
- 模式退出、完成和舰桥导航都会清理对应的 interval / timeout，避免切页后继续运行。
- 普通敌人开火前显示 `FIRE` 方向线；Boss 攻击前显示 `LOCK` 预警；刀锋敌人冲刺前显示 `DASH` 目标标记。
- 浮动数字区分舰体伤害与护盾伤害，关键命中、Boss 破盾和受到攻击会产生轻量屏幕反馈。
- 开局说明与威胁图鉴补充了“看预警、看反馈”的实际操作说明。
- 动态页新增 v25 战斗可读性记录；测试覆盖运行时清理、攻击预警和反馈状态。

## 下一阶段安排

### v26-A：敌人与 Boss 的视觉重做

目标是让每类敌人从轮廓、朝向和攻击姿态上都能一眼区分。先处理 Boss 与最常见的四类敌机，再扩展到变异敌群。

- 重新检查每个 atlas 的透明边界、朝向和缩放比例。
- 为炮舰、火力艇、刀锋、炮台和精英建立不同的攻击姿态或发光部位。
- 给四种 Boss 各自保留一套可识别的攻击颜色、预警形状和阶段变化。
- 用图鉴和战斗画面同时验收，避免“卡片好看但战斗中看不出来”。

### v26-B：战斗节奏与数值验收

- 记录前摇时长、弹幕密度、Boss 护盾窗口和 EMP / 瞬闪冷却的实际关系。
- 用固定种子跑标准、风暴、回收、深渊四条航线，检查节点修饰是否真的改变决策。
- 增加不依赖无敌保护的短局试玩记录，单独观察前 5 波和首个 Boss 的可生存性。
- 继续保持长时间模拟的对象数量和弹幕上限。

### v26-C：导航与模式边界

- 把主战斗、短局、内容页的进入 / 开始 / 暂停 / 完成 / 退出动作整理成统一清单。
- 移动端优先检查舰桥横向导航、内容筛选、战斗 HUD 和短局按钮的触控尺寸。
- 如果后续继续拆分 `game.js`，优先抽出模式生命周期和渲染辅助函数，避免一次性迁移整个文件。

## 不提前做的事情

账号、云同步、在线排行榜、多人模式和大规模后端服务都等到主战斗完成一轮真实设备验收后再决定。当前站点的免登录和本机存档边界是可用体验的一部分。

## 验收门槛

- 构建、核心测试、回归测试和静态检查全部通过。
- 公开地址能返回首页、脚本、运行时模块和当前使用的美术资源。
- 选航线、开始战斗、短局切换、暂停、返回舰桥和内容筛选不出现运行时错误。
- 320×568、390×844 和 844×390 不产生页面级横向溢出。
- 真实 Android / iOS / Safari 和长期数值平衡仍需单独验证，不能用 Node 模拟替代。
