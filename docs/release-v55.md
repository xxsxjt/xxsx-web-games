# V55 自由战场

霓虹突围默认使用 3200 × 2400 世界坐标与跟随镜头。触屏使用相对浮动摇杆，键盘方向只控制移动，主炮自动锁定镜头附近最近的敌人，并使用少量切换迟滞避免反复抖动。敌人从四周进入，近战追击、远程保持距离，Boss 贴近后侧向移动；地图边缘优先选择离玩家足够远的屏外位置。

击破产生经验晶体，145 范围内吸取；经验晶体有寿命和数量上限。三个补给站需要在附近没有敌人的情况下守住五秒，每站只发一次维修、EMP、强化芯片和废料。占领进度受到敌人干扰，离开后缓慢衰减。小地图显示玩家、镜头范围和补给站；旧底部越界伤害不在自由战场触发。

保留武器与辅助武器、四种 Boss、路线事件、战役与无尽、构筑路线及原档案键。辅助光束和散射方向也改为朝目标开火。页面改变尺寸只调整镜头，不缩放战场物体。暂停、升级、失去触摸和页面隐藏清除摇杆，恢复后重新输入。旧缓存页面未加载新模块时可使用原战斗逻辑。

其他五款小幅改进：战术提示剩余 AP；解码显示当前可获星级并提前说明提示代价；卡牌显示真实蓄能结束预估与下回合能量；打捞装载按钮尊重剩余容量并显示冷却耗氧；塔防显示实际回收资金和优先级含义。

新作品方案见 new-game-concepts-v55.md。尚未上线第七款游戏。

验证：构建和项目自动检查；世界边界、四向生成、目标切换、经验拾取、争夺阻断和一次结算；实际战斗模拟覆盖镜头移动、窗口尺寸变化和五分钟对象回收。浏览器已验证新版入口、开局与战斗 HUD。仍需人类长局试玩判断难度、构筑强度及移动手感；本局战斗仍不支持刷新恢复。
