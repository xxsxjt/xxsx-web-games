# V58：八款作品总站、独立解谜切片与可靠发布底座

## 本轮调整

- 构建时将发布文本资源统一规范为 LF，再计算源和发布哈希。这样 `core.autocrlf=true` 的 Windows 工作区不再让版本清单与已提交源文件发生换行差异；PNG、WebP 等二进制资源仍按原始字节处理。
- 静态发布检查确认清单版本为 V58、源文件哈希按规范化内容计算、发布文本不含 CRLF，并验证七款作品均已登记。
- 《寄壳行动》开局提示现在明确指向一格内的第一步；未启动护盾时，任何操控对象都不能穿越激光格。
- 地图格改为带坐标及内容说明的语义网格单元，避免把不能点击的地图格伪装成按钮。
- 通关后在 `xxsxShellHeistV1` 记录通关数、最佳回合数和最近能力路线；不清理或覆盖其他游戏存档。
- 页面路由切换会先收起全部独立游戏页；离开寄壳行动时移除键盘监听，避免重复进入造成监听器叠加。
- 总站加入组合搜索、类型与收藏筛选、可信结果数和空态；保留 `xxsxWebGamesHubV1`，兼容旧收藏及最近打开记录。
- 新增独立游戏《寄壳行动》（三舱段、四类壳体、提示/撤销/逐步存档）和《借来的十秒》（四房间、十拍回声、时间线、通关记录），不复用或改写其他游戏存档。
- 旧 `play.html#game/shell` 和 `play.html#station/shell` 书签在加载旧游戏脚本前转到独立页面。
- 《借来的十秒》使用 `xxsxBorrowedSecondsV1` 存通关进度，不持久化每轮动作或完整录像。
- 《边境战术》高价值回收首舱敌人起始格错开；战术存档现在同时校验主档、待提交档与恢复备份，检测到其他标签页更新时阻止操作/放弃覆盖并提示重新载入。
- 发布器加入 75 项历史资源独立 SHA-256 清单，验证历史 URL、文本 LF、所有本地引用及独立 HTML 入口；先暂存并校验完整构建，成功后才替换 `dist/`，失败保留现有发布产物。

## 验证

- `npm run build`：通过，生成 V58 发布清单；构建输出主页 HTML/CSS/JS/目录 gzip 合计 12,313 bytes（图标另计）。
- `npm test`：通过；包含核心和旧战役回归、总站与独立游戏交互测试、边境战术逐步通关及并行标签页冲突、历史 URL/引用/失败构建保护、纯静态预览和构建产物回归。
- 发布资源：manifest 为 V58，包含 43 个本版文件、75 个独立固定历史资源哈希和 16 个旧别名；75 个历史哈希与 Git 基线资源内容相符。
- Orca 本机 `dist/` 浏览器：总站组合筛选/收藏刷新通过；320/375/414/768px 均无横向溢出，卡片未越界，触控目标至少 44px。使用总站实际入口打开《借来的十秒》，完成首房间通关、下一房间十拍耗尽反馈、重试、刷新后状态/解锁恢复；该页四种宽度同样无溢出且触控目标至少 44px。
- Orca 本机 `dist/` 浏览器：《寄壳行动》路线 A 完成第一舱/失败反馈/撤销后通关；路线 B 自第一舱开始逐步续档后通关；刷新恢复最终记录。旧 `#game/shell`、`#station/shell` 两个书签均跳转至独立入口。
- 实体 Android/iOS 设备、长时间平衡与公开 Sites 部署不在本次实测范围。
