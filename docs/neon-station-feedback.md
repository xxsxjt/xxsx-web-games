# 霓虹突围：补给站状态反馈切片

状态由 src/freefield.js 的 beaconStatus 只读派生：已占领、未进入范围、敌人干扰、正在充能。判定沿用自由战场世界坐标；玩家距站点严格小于 85 才进入范围，敌人距站点严格小于 125 才构成干扰。距离边界与既有充能规则一致，状态读取不写 charge、claimed、坐标或存档。

主战场和雷达均对每个站调用同一个 beaconStatus，用不同轮廓/图形并配文字呈现状态；雷达继续显示三站位置、玩家位置和视野框。占领奖励与单局初始化未改变。

定向回归：node tests/station-feedback.cjs 覆盖 85/125 精确边界及内侧、死敌排除、状态读取只读、一次性占领、两处生产渲染和重开清零。并需通过既有 node tests/freefield.cjs 与 node tests/regression.cjs。这三项是无窗口 Node/VM 检查，不代表浏览器/320×568 设备可读性或真人试玩；本任务未获 UI 自动化与图形试玩授权，未做这些验证，也未改 dist/、提交或推送。
