# 废土杂货铺 — 游戏设计文档 v0.1

> 工作标题：废土杂货铺（Wasteland Shop）
> 文档状态：概念设计阶段
> 最后更新：2026-10-13

---

## 一、核心定位

**一句话描述**：在资源匮乏的废土世界里，经营一家以格子仓库为核心的二手杂货铺——收货、鉴定、造假、拍卖、生产、派遣，在执法与黑市之间寻找生存空间。

**核心体验**：
- 格子整理的空间焦虑与满足感
- 信息不对称下的博弈（集装箱拍卖、假货鉴定）
- 经营压力下的资源分配决策
- 废土社会的人际网络与声誉管理

**不做的事**：玩家自己进图搜索（至少初版不做）。

---

## 二、世界观背景

资源严重匮乏的后灾难世界。基础物资（水、食物、电力、药品）均处于短缺状态，拾荒者文化盛行，黑市与执法力量并存，各方势力对资源的争夺形成复杂的社会生态。玩家是其中一个试图在夹缝中经营立足的小商人。

## 三、时间系统

### 3.1 基本单位

游戏以**天**为推进单位。玩家主动"结束今天"触发日结算，不会实时流逝。

店铺营业期间，时间以**小时**粒度推进，影响客流节奏和事件触发，但玩家不需要实时操作——系统自动处理客流，玩家响应插入的事件。

### 3.2 时间层级

| 层级 | 周期 | 主要用途 |
|------|------|----------|
| 小时 | 店内营业时段 | 客流节奏、事件触发时段 |
| 天 | 基本操作周期 | 生产进度、派遣推进、日结算 |
| 周 | 经济压力节点 | 租金结算、集装箱拍卖场次 |
| 不定期 | 世界事件 | 市场行情波动、执法力度变化、断供事件 |

### 3.3 各系统时间消耗

**派遣搜查**：
- 近郊：1-2天，低风险，普通物资
- 中距离：3-5天，中风险，可能有稀有物
- 深入禁区：7-14天，高风险，可能失联
- 受伤恢复：额外1-3天，恢复中不可再派

**生产加工**：
- 熔炼：4-8小时（跨天，次日出结果）
- 烹饪/简单加工：1-4小时（当天内）
- 种植：3-14天（视作物）
- 制药：1-3天（复杂配方更长）
- 充电：按电量线性，普通电池2-4小时
- 酿酒：基础发酵7-14天，陈年额外计时（存放越久价值越高）

**鉴定**：玩家主动放大查看，不消耗时间槽，靠玩家自身操作和积累的笔记/熟练度。

**集装箱拍卖**：每周一场，提前1-2天公示线索；拍卖当天为回合制出价，拍到后运输需1天。

### 3.4 日结算流程

玩家结束当天时，按序结算：

1. 生产进度推进
2. 派遣进度推进，到达天数者触发返回/事件
3. 店铺客流结算（成交、偷窃、纠纷）
4. 消耗品保质期损耗
5. 玩家吃喝消耗（从库存取用）
6. 健康状态检定（营养/疲劳/患病概率）
7. 针剂依赖检定（如有使用）
8. 若为周末：扣租金，刷新市场部分信息
9. 随机事件检定（执法巡查、情报贩子、陌生人造访等）

## 四、仓库与格子系统

### 4.1 核心设计原则

格子始终是瓶颈。仓库空间是战略资源，不是无限容器。

### 4.2 仓库类型

| 仓库类型 | 说明 |
|----------|------|
| 主仓库 | 基础格子存储，可升级扩容 |
| 温控仓 | 食物/药品/特定化学品需要，否则加速腐化 |
| 酒窖 | 酿酒陈年专用，控温控湿，影响陈年质量 |
| 暗格 | 隐藏存储违禁品，可升级隐蔽等级 |
| 隐藏仓库 | 店外独立地点，深度搜查才能发现 |

### 4.3 物品属性

每件物品占据固定格子形状（参考塔科夫），属性包括：
- 尺寸（格子占位）
- 重量
- 品质/纯度（影响售价、用途效果）
- 保质期（部分物品）
- 真实性（正品/仿品，可被检测）
- 来源标记（影响某些角色的接受度）

## 五、派遣系统

### 5.1 派遣员机制

派遣员是**随机上门**的NPC，接受任务后出发，不是固定雇员。同一个人可能同时是你的顾客、集装箱拍卖竞争对手、以及派遣员——身份由角色标签决定，包含"可接受派遣"标签的角色才能被派遣。

派遣数量无上限，但受制于：
- 派遣设施等级（同时出发的上限）
- 声望（高声望吸引更多人愿意来，甚至有人主动申请）
- 报酬吸引力（物资或金钱，报酬越好人越愿意去危险地方）

### 5.2 派遣员差异化

每个派遣员有个人标签影响派遣结果：

- **地形标签**：擅长城区/野外/工业区，影响对应地区的搜索效率
- **体力标签**：影响能执行的最远距离任务
- **武装标签**：有无武器/武器类型，影响遭遇战存活率
- **搜索标签**：擅长特定物资类型（电子/食物/医疗/机械）
- **可靠性标签**：影响报告的准确度和物资带回率

### 5.3 派遣结果

- 平安归来（带回物资）
- 平安归来（空手，发现什么但带不回来）
- 受伤归来（物资减少，需要恢复期）
- 失联（需要花资源搜救，或等待，或放弃）
- 阵亡（极端情况，该角色从游戏中移除）

### 5.4 随机事件（派遣途中）

- 发现额外物资缓存
- 遭遇其他拾荒者（可能冲突或合作）
- 发现情报（带回市场/地形信息）
- 遭遇执法巡逻（有武装标签影响结果）
- 发现可疑物品（来路不明，可能违禁）

## 六、集装箱拍卖系统

### 6.1 基本流程

每周一场，提前1-2天公示待拍集装箱。每个集装箱有2-4条线索，玩家据此推理内容物并决定出价。

### 6.2 线索类型

- 外观线索：箱子重量、锁的品牌、外部损伤状态、港口来源标记
- 气味/声音线索（需要靠近检查）
- 情报线索（提前花钱从情报贩子处购买）
- 上一任持有人的职业/身份（公开记录可查）

### 6.3 估价系统

玩家和AI竞拍者都使用同一套逻辑：
1. 根据已知线索估算**底价**（已知线索下的最低合理价值）
2. 根据自身身份/预算/喜好决定**溢价比例**（愿意在底价上多付多少）

玩家手动出价；AI自动根据自身标签计算。

### 6.4 AI竞拍者

每个AI竞拍者是完整随机生成的角色（见第十一章角色系统），有：
- 随机资金（独立于购物预算）
- 身份决定的物资偏好（影响溢价意愿）
- 阵营（可能在拍卖场发起社交事件）

**阵营社交事件示例**：某AI私信"让一让这个集装箱，我们会记得你的好"——玩家可以接受（获得该阵营声誉）或拒绝（继续竞拍但关系扣分）。

### 6.5 集装箱档位

多个档位，线索数量和质量不同，起拍价也不同：
- 低档：1-2条线索，来源混杂，风险高意外多
- 中档：2-3条线索，来源相对可信
- 高档：3-4条线索，可查历史记录，竞争激烈

## 七、开店系统

### 7.1 基础运营

店铺每天营业，自动产生客流。玩家不做繁琐的定价设置，交易在柜台上一次谈成：
- 选中货物上柜台 → 商旅出价 → 成交或收回
- 商旅上门时同时带货（卖给你）和要货（向你买）

### 7.2 货源：前期没有稳定供货渠道

这是本作经济模型的核心。**前期玩家没有进货渠道**，货物只能从两个来源来：

1. **商旅上门兜售**：每位来访商旅除了想买东西，还会带来一批自己的货，愿意按市场价出手。
2. **拍卖**（每周一场，见第六章）。

也就是说，玩家赚的是**周转差价**：

| 环节 | 价格 | 说明 |
|------|------|------|
| 回收价 | ≈ 市场均价 | 从上门商旅手里收货，基本按市价，不会白捡 |
| 零售价 | 市场均价 × 溢价 | 卖给需要的商旅；对方身份决定溢价高低（0.6–1.4） |

利润来自三处：
- **行情波动**：低系数时收进、高系数时卖出（主要利润来源）
- **需求匹配**：卖给"正好需要这个类目"的商旅，溢价更高
- **鉴定差价**：看得出仿品的，低价收进也能正常卖出；看不出则要担责

> 设计意图：前期资金紧张、货源零散，逼玩家盯着行情和客人做小本周转，而不是坐在店里等补货。

### 7.3 人脉与订购（后期解锁）

稳定供货渠道是**逐步解锁**出来的，不是开局就有。

- 每位**供货商**掌握某一类物资（例如某品牌啤酒、某个药厂的药品），解锁后可以**订购**。
- 订购与随时买卖不同：**下单即付款、数天后到货**，中途不能反悔；到货进仓库，卖不卖得出去是玩家自己的判断。
- 解锁条件可以是声誉、累计成交额、特定事件（例如帮某个商旅解决过麻烦），解锁后写入档案。
- 供货商货品带**品牌/来源标识**（品牌名、产地），同一类目下不同品牌价格与品质不同，形成"进货眼光"。

> 已实现：访客双向交易见 7.7；人脉订购见 7.3 与 7.7。

### 7.4 经济压力

- **租金**：每周结算，早期主要压力来源
- **停业**：欠款且既无货可卖、也进不起货时停业，可重新开张
- **买下店铺**：需要达到特定资金门槛，买下后无租金压力（后续发展待设计）

### 7.5 搜查机制

执法方会定期巡查。搜查有三个深度档位：

| 档位 | 触发条件 | 能发现内容 |
|------|----------|------------|
| 例行检查 | 定期 | 明面上的违禁品 |
| 重点排查 | 声誉/阵营关系恶化 | 普通暗格 |
| 彻查 | 被举报/重大违规 | 高级暗格，需要足够隐蔽等级才能躲过 |

**触发深度搜查的多重条件**（需要多项同时满足才会出现）：
- 累计总盈利超过阈值
- 当前持有资金较高
- 总资产（含物品）超过阈值
- 游戏天数（经营时间够长）
- 与黑市阵营的声誉过高
- 近期有客户投诉

前期设计保证不会出现深度检查，首次出现时有明确预警提示。

### 7.6 其他店铺事件

- **小偷**：概率出现，角色标签决定手法，声誉和安保设施影响频率
- **骚扰**：某些阵营的势力可能来施压
- **突发交易机会**：上门的批发商、急于出手的散货

### 7.7 访客双向交易（已实现）

每位商旅每天到店时带两样东西：

| 字段 | 含义 | 用途 |
|------|------|------|
| `offers` | 他带来的货（1–3 宗，按身份决定类目） | 玩家可**收购**，价 = 市价 × 0.88–1.05 |
| `wants` | 他想要的类目 | 玩家**卖出**时的需求匹配依据 |

身份与货品倾向：

| 身份 | 带来的货 | 想买的东西 |
|------|----------|------------|
| 拾荒者 | 常规物资为主：废品、水、食物、材料、布料 | 烟酒、武器装备、药品 |
| 商人 | 材料、电子 | 材料、电子 |
| 医护 | 药品 | 药品 |
| 收藏家 | 酒类（含陈年） | 酒类 |
| 工地采购 | 材料 | 材料 |
| 情报贩子 | 无（只卖情报） | — |

**收购价**：`市场均价 × (0.88 ~ 1.05)`，随身份浮动——拾荒者急于出手，压得低；商人惜售，要价高。
**卖出价**：沿用柜台议价（`市价 × 身份溢价 × 态度 × 需求匹配`），上限受对方预算约束。

> 关键点：收购价与卖出价都锚定市场均价，所以**行情系数才是真正的利润杠杆**。

## 八、生产系统（已实装）

### 8.1 概述

**生产是让 179 件货各有用处的唯一手段**，不是锦上添花。实装前的审计结论很直白：
全目录 153 件货里，122 件能拿到的货只有一个用途——低买高卖；29 件根本进不了游戏。
现在每一件都有入口，而且大部分都有下游。

三条硬规则，全部由测试钉住（`tests/wasteland-shop.cjs`）：

1. **成品比原料值钱**——每道配方的成品目录价 ≥ 原料的 1.5 倍，实测 1.8–3.1 倍。
2. **炼废了是真亏**——失败只出副产物，副产物价值必须低于原料，但不能是零。
3. **没电不干活**——机器断电时批次原地等待，不推进天数、也不再吃料。

数据定义在 `src/wasteland-core.js` 的 `MACHINE_DEFS` / `RECIPE_DEFS`（6 台机器 / 20 道配方），
逻辑在 `src/wasteland-shop.js`（`buyMachine` / `startProduction` / `_tickProduction`）。

### 8.2 机器区

机器放在 **`baseState.freeGrid`（4×3）**，和堆货的仓库是**两块地方**——这是用户明确要求的分区。

- 机器按世界划分：废土的机器在废土买，宗门的机器在宗门买，串门买不到
- 机器有等级；等级只做一件事：把该机器上配方的失败率每级压低 4 个百分点（下限 2%）
- 一台机器同一时间只跑一批活（`_machineBusy`）
- 买机器要钱（¤200–650），且要摆在机器区里摆得下

### 8.4 灵霄宗门界的炼丹链

原料便宜、成品极贵，但失败率也最高——这就是「炼丹炼废了」的机制本体。

| 配方 | 吃 | 出 | 天 | 失败率 | 倍率 |
|---|---|---|---|---|---|
| 种灵草（灵田） | 药草种子×1 + 培养土×1 | 灵草×6 | 4 | 15% | 2.0× |
| 种火炎花（灵田） | 药草种子×1 + 木炭×1 | 火炎花×3 | 5 | 20% | 2.0× |
| 炼回气丹 | 灵草×3 + 丹砂矿×1 | 回气丹×2 | 2 | 20% | 3.0× |
| 炼凝神丹 | 灵草×2 + 灵砂×2 + 灵液×1 | 凝神丹×2 | 3 | 25% | 2.5× |
| 炼疗伤丹 | 灵芝×1 + 灵液×1 | 疗伤丹×1 | 3 | 25% | 2.3× |
| 炼毒丹 | 毒液×2 + 火炎花×2 | 毒丹×2 | 2 | 22% | 2.1× |
| **炼洗髓丹** | 妖兽内丹×1 + 灵石×1 + 灵芝×2 | 洗髓丹×1 | **7** | **40%** | 1.9× |
| 画阵盘（符箓台） | 符纸×2 + 朱砂墨×1 | 阵盘×1 | 2 | 20% | 2.1× |
| 刻宗门令牌（符箓台） | 朱砂墨×1 + 灵砂×1 | 宗门令牌×1 | 1 | 15% | 2.1× |

失败一律出**废丹**（¤22）。洗髓丹是最贵的成品（¤1200）也是最能亏的配方：
七成原料是妖兽内丹（¤380）+ 灵石（¤150），失败三次就是一台丹炉的钱。

### 8.5 世界与选址

不再有「穿越世界」这套设定——游戏里**没有穿越时间的能力**，所以名字里的「时空」是遗留物（见待办）。

实际规则：

- 关店后玩家待在**空间夹层**（不属于任何世界）
- 每天开门前**选一个世界**，界门开在那个世界的**随机地点**（如锈带集市、丹霞谷口）
- **当天只能换一次**，换完锁死；一旦开始接客/成交也锁死
  ——不锁的话可以反复转场刷客商，「今天来谁」的随机性就没了（这个漏洞真的出现过）
- 今天来的商旅**只出自这一界**（情报贩子中立，哪一界都可能有）

**两个世界做深，其余九个标注「开发中」**（`WORLD_ORDER[].status`）：
核爆废土、灵霄宗门界是 `playable`，其余为 `wip`，在界门面板里显示为不可点的灰卡。

> 注意：`WORLD_ORDER` 的顺序**不能重排**——旧存档的访客世界是按数组下标存的
> （`LEGACY_VISITOR_WORLD_ORDER`），挪位就会把老档的商旅送到错的世界。

### 8.6 已移除的旧设计

以下章节描述的玩法**没有实装，且已不在计划内**，保留在此仅作记录：
土壤类型/剪枝方案/施肥配方等深度农艺参数、酒窖陈年、烹饪、
原料造假与年份造假、派遣员实物报酬。陈年酒仍能通过收藏家卖高价（`wantAged`），
但酒不是自己酿的，是从商旅手里收的。

## 九、假货与鉴定系统

### 9.1 造假

任何商品都可以通过**改标签**造假。造假需要：
- **伪造道具**：印章、模具、旧包装、试剂、年份标签等，本身是可被搜查的违禁品，来源同样是派遣/集装箱/黑市
- **时间成本**：不同商品造假步骤不同，耗时不同
- **风险成本**：持有伪造道具本身有风险

**可造假维度举例**：
- 金属：以青铜充金，贴标签
- 水/化学品：纯度造假，外观相似难辨别
- 药品：成分替换、剂量不准
- 酒：原料造假、年份造假
- 食物：来源造假、品质虚标
- 针剂：成分替换（安慰剂或有害替代物）

### 9.2 鉴定机制

鉴定结果分三类：

| 情况 | 条件 | 结论 |
|------|------|------|
| 工具检测 | 有对应工具 | 确定性结论，当面操作，双方可见，无法抵赖 |
| 技能估算 | 无工具，靠经验 | 概率判断，仅玩家可见，告知客人后对方是否相信取决于声誉和客人标签 |
| 完全无据 | 技能不够且无工具 | 无信息，纯赌 |

**技能树对估算准确度的影响**：
- 低级：显示概率随机性大，可能严重偏离真实值
- 高级：概率越来越接近真实值
- 满级某品类：概率几乎准确，但仍非100%（工具才是确定性结论）

**工具检测的特性**：检测在客人面前进行，结果双方共知，对交易双方均有约束力。

**技能估算的特性**：结论是玩家的主观判断，告知客人后，客人是否相信取决于：
- 玩家当前声誉（声誉越高，话语分量越重）
- 客人标签（多疑型客人对口头判断半信半疑，即使声誉高也可能怀疑）

**鉴定工具来源**：部分初级工具由教程赠送，其余从博士NPC购买或集装箱/派遣获取。

### 9.3 假货责任链

**玩家卖假货的后果类型**（由角色标签决定）：
- 当场发现 → 当面冲突，可道歉赔偿或翻脸
- 回去使用后发现 → 延迟反馈，几天后触发：
  - 当面回店投诉
  - 投纸条（知道有问题但不知道是哪笔）
  - 静默扣好感（不公开，影响力低的人不扩散）
  - 向社区散布（声誉扣分，扩散程度看影响力）
  - 举报执法（触发搜查）
  - 沉默吃亏（部分人不追究）
- 有能力鉴定却未鉴定就卖出：声誉惩罚更重
- 无能力识别：惩罚较轻，系统公平

**玩家收假货**：收了再卖给下家，下家发现后追溯到玩家，同样扣声誉。

## 十、声誉系统

### 10.1 声誉来源

- **增长**：有交易自然增长（口碑积累）、服务好、公平交易
- **下降**：卖假货被发现、违约、得罪阵营、被投诉举报

### 10.2 声誉效果

| 声誉水平 | 效果 |
|----------|------|
| 低 | 客流少、拍卖场被孤立、被频繁搜查 |
| 中 | 正常运营 |
| 高 | 更多客流、更好渠道、执法较少打扰 |
| 极高 | 部分人主动来投靠（免费帮忙）、派遣员折扣甚至白干 |

### 10.3 阵营声誉

| 阵营 | 特点 |
|------|------|
| 执法方 | 高声誉减少搜查；举报违禁品加分；和黑市来往扣分 |
| 黑市 | 高声誉解锁违禁品渠道；上报违禁物资扣分（无主物资除外） |
| 拾荒者群体 | 高声誉带来更多派遣员和情报 |
| 各势力/阵营 | 影响集装箱拍卖社交事件、特殊商品渠道 |

### 10.4 深度搜查触发条件（多项同时满足）

累计总盈利超阈值 + 当前持有资金高 + 总资产超阈值 + 经营天数足够 + 黑市声誉较高 + 近期有投诉。前期不会出现，首次出现有预警。

## 十一、角色系统与标签池

### 11.1 角色生成机制

所有NPC从同一套系统随机生成，同一角色可身兼多种功能（今天是派遣员，下次是顾客，拍卖场是竞争对手）。

生成内容：随机姓名 / 外观（多部位预设组合）/ 总资金 / 各类标签

### 11.2 标签池

**身份标签**：

| 标签 | 说明 |
|------|------|
| 拾荒者 | 低预算，接受破旧物品，对高价抵触 |
| 工地采购 | 批量需求建材/工具，不接受化学品/贵金属/电子 |
| 黑市商人 | 对违禁品感兴趣，有黑市渠道 |
| 执法人员 | 不接受违禁品，注意合规，出现时需谨慎 |
| 医疗工作者 | 优先购买药品，鉴定药品能力强 |
| 工程师/技术人员 | 购买电子/机械，鉴定机械电子能力强 |
| 农场主 | 购买种子/农具，可提供食材来源 |
| 酿酒师 | 对酒品质要求高，不易被低质酒蒙骗 |
| 势力代表 | 背后有组织，来往影响阵营声誉 |
| 情报贩子 | 主动带来信息，也可购买/出售情报 |
| 可接受派遣 | 该角色可被玩家派遣执行搜查任务（见第五章） |

**阵营标签**：执法派 / 黑市派 / 中立 / 各势力派系

**性格标签**：

| 标签 | 说明 |
|------|------|
| 记仇 | 被骗后必然报复 |
| 软弱 | 被骗后沉默吃亏（与记仇互斥） |
| 守法 | 发现违禁倾向举报 |
| 地头蛇 | 社区影响力大，坏话传播范围广 |
| 健谈 | 主动散布信息（好坏皆可） |
| 多疑 | 鉴定倾向强，不易被蒙骗 |
| 冲动 | 竞拍溢价比例高（与谨慎互斥） |
| 谨慎 | 出价保守，不轻易溢价 |
| 嗜酒 | 对酒有特殊偏好，溢价意愿高（与清醒主义者互斥） |
| 清醒主义者 | 不购买酒/成瘾性物品 |
| 仗义 | 拍卖场等场合可能帮助玩家 |

**能力标签**：

| 标签 | 说明 |
|------|------|
| 鉴定专家:金属/化学/食品 | 对应类别假货难蒙骗（与容易被骗互斥） |
| 容易被骗 | 鉴定能力低 |
| 擅长城区/野外/工业区搜索 | 对应地形派遣效率高 |
| 高体力 | 可执行远距离派遣 |
| 武装 | 有武器，遭遇战存活率高 |
| 搜索:电子/医疗/食物/机械 | 派遣偏向对应物资 |
| 可靠 / 不可靠 | 影响派遣报告准确率和物资带回率 |

**购物标签**：

| 标签 | 说明 |
|------|------|
| 批发买家 | 倾向大量购买，压低单价 |
| 批发卖家 | 上门批量出售 |
| 急于出手 | 售出价格更低 |
| 急于购买 | 接受高价，不砍价 |
| 只买套装 | 要求配套商品 |
| 指定规格 | 对纯度/尺寸有要求 |
| 分期付款 | 批量订单延迟付清，有违约风险 |

### 11.3 标签互斥规则

生成角色时以下标签不能同时出现：

| 互斥组 | 说明 |
|--------|------|
| 嗜酒 ↔ 清醒主义者 | 行为逻辑对立 |
| 鉴定专家（任意类别）↔ 容易被骗 | 能力逻辑对立 |
| 记仇 ↔ 软弱 | 性格逻辑对立 |
| 冲动 ↔ 谨慎 | 决策逻辑对立 |

### 11.4 角色记忆

每个角色维护：关系值 + 关键事件列表（最近3-5条）。影响后续交互选项和态度。

## 十三、市场行情系统

由**实际供给驱动**，不是固定周期。集装箱批次决定市场，玩家感受因果。

**断供等级**：
- 缺货涨价：短期减少，数天后恢复
- 彻底断供：完全中断，价格极度疯涨，玩家自身储备也要撑过去

**行情预兆**：情报贩子付费消息 / 拍卖场上某类物品批量出现（免费可观察）

## 十四、玩家角色系统

### 14.1 基础需求

- 每天从库存取用食物/水（不强制烹饪，但烹饪提升效果上限）
- 不同种类和品质有不同效果，长期单一饮食有负面效果
- 断供时自身储备变成生存资源

### 14.2 健康状态

患病机制：超过健康阈值越多，触发概率越高（非硬触发）。

患病来源：处理受污染物资 / 食用低质食物水 / 派遣员带回的感染 / 长期恶劣环境工作

生病影响（对应现实合理设置）：
- 发烧：判断力/谈判/鉴定成功率降低
- 手抖：鉴定精度下降
- 体力不足：当天行动点减少
- 中毒：需解毒针清除

### 14.3 技能树方向

谈判 / 各品类鉴定 / 体力健康耐受 / 生产技艺 / 管理派遣效率（详细节点待设计）

## 十五、针剂系统

### 15.1 来源

博士NPC（安全贵）/ 自制（可控需配方）/ 派遣获取（随机）/ 集装箱开出（存疑）/ 黑市（高效高风险）

### 15.2 分类

- **急性类**：止痛剂、应急兴奋剂、消炎针、解毒针
- **强化类（疗程）**：体能强化、神经增强、免疫强化
- **成瘾性类**：高效兴奋剂、认知增强剂

### 15.3 副作用机制

三参数：纯度 / 耐药阈值 / 依赖性

依赖状态：停用属性低于基准，戒断症状持续数天，特定配方可辅助戒断。

假针剂风险：零效果安慰剂 / 额外中毒副作用 / 剂量不准过激反应

## 十六、暗格与隐藏仓库

- **暗格**：店内，可升级隐蔽等级，例行检查不发现，彻查需高级暗格才能躲过
- **隐藏仓库**：店外独立地点，更安全，运输需时间，解锁有条件门槛

## 十七、黑市系统

需要黑市阵营声誉达标才能接触。

违禁物资处理选项：上报执法（执法声誉+）/ 私留销售（高价但持续风险）/ 销毁（安全但损失）

与黑市来往越深，执法搜查频率越高，形成持续张力。
