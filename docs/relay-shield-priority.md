# 信号中继：护盾优先目标模式

炮塔目标按钮现在按 first → strong → fast → shield → first 循环。旧三种模式的含义保持不变：前端（最接近核心）、高生命和高速。护盾优先模式只在该炮塔射程内的可攻击敌人中挑选：有盾目标优先；同组按到核心的进度排序，进度完全相同则较小的敌人 ID 优先。射程内没有带盾目标时，回退到最接近核心的可攻击目标。

炮位控制按钮沿用现有 44px 最小触控高度；侧栏说明文字复述当前目标策略，不依赖颜色表达。模式只改变目标选择，不改变炮塔射程、伤害、护盾吸收、波次、路径、经济或其他模拟规则。

## 存档兼容

- 存档键仍为 xxsxRelayDefenseV1，状态仍是 version: 1；不新增状态字段、不迁移或清理存档。
- 含 first、strong 或 fast 的旧版本 1 存档仍通过 R.valid 并原样加载。
- 新版允许将现有炮塔 priority 写为 shield。
- 旧版代码不认识新增的 shield 枚举，因此由新版保存了 shield 的进行中战局，不保证旧版代码可继续读取。此限制不影响旧枚举存档的兼容性。
