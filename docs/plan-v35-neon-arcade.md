# Neon Drift v35 / Neon Arcade 扩展计划

## 本轮目标

把 Neon Drift 从“打开就进入舰桥的单体游戏”改成“先进入游戏大厅，再进入独立子游戏”的站点结构。

## 已实现的入口层

- `#arcade`：Neon Arcade 游戏大厅，作为站点默认首页。
- `#game/expedition`：霓虹突围远征，进入原有舰桥与 Roguelite 主玩法。
- `#game/relay`：信号中继，进入 20 秒反应短局。
- `#game/lab`：回声实验室，进入 30 秒记忆序列短局。
- 所有子页面都能通过“游戏大厅”返回外层入口。
- 公告仍以悬浮窗形式打开，不再要求用户进入站点动态页才能看到最新版本。

## 三款游戏的分工

| 子游戏 | 核心动词 | 主要回流 | 入口验收 |
|---|---|---|---|
| 霓虹突围 | 构筑、走位、战斗 | 远征次数、星尘、装备、蓝图、日志 | 进入舰桥、开始出击、返回舰桥 |
| 信号中继 | 捕获、连击、反应 | 中继最高分、命中数、站点委托、星尘 | 进入信号台、启动短局、返回大厅 |
| 回声实验室 | 观察、复现、加压 | 实验最高分、完成轮数、蓝图、日志 | 进入实验室、启动实验、返回大厅 |

## 下一阶段扩展

1. 将深空打捞重构为大厅中的第四张独立游戏卡，并保留舰桥内的站点入口。
2. 增加统一“最近游玩 / 继续上次活动”卡，直接把玩家带回上次进入的子页面。
3. 为每个子游戏补一张独立的教学页和完成结算页，让首次玩法说明不依赖舰桥文案。
4. 增加跨游戏每日种子、共享任务和蓝图解锁展示，让短局与远征之间形成更明显的因果链。
5. 继续做手机优先验收：首屏卡片、返回大厅、公告悬浮窗和子页面控件都保持至少 44px 触控目标。

## 本轮验收门槛

- 自动化回归覆盖：三款入口切换、共享档案数字、短局计时器退出清理。
- 构建产物由 `npm run build` 生成，部署包与绑定提交一致。
- 公开地址验证默认进入大厅，三张卡分别能打开对应子页面。
- 桌面、390×844、320×568、844×390 均检查页面级横向溢出。
- 应用自身控制台错误保持为 0；真实 Android、iOS Safari 和长期数值平衡仍需后续设备验收。
