## 一、核心定位

**一句话**：你在维度交汇处开了一家店，买卖来自不同世界的物资，靠信息差和价差获利。

**核心体验循环**：
- 打开传送门前往某世界 → 采购/销售
- 拍卖"维度漂流物"（来源不明的跨界货物）
- 通过信息差预测哪个世界即将短缺/过剩
- 管理跨维度库存与资金

## 三、价差系统

### 3.1 世界价格乘数矩阵（示意）

物品类别 × 世界 = 乘数（1.0为标准价）

| 物品 | 核爆废土 | 瘟疫荒原 | 机械末日 | 修仙宗门 | 蒸汽帝国 | 赛博魔法 | 中世纪 | 星际外站 |
|------|----------|----------|----------|----------|----------|----------|--------|----------|
| 净水 | 4.0 | 3.5 | 2.5 | 0.5 | 1.2 | 1.0 | 0.8 | 0.6 |
| 金属 | 0.3 | 0.4 | 0.2 | 1.5 | 0.3 | 0.8 | 1.0 | 2.0 |
| 药品 | 5.0 | 6.0 | 3.0 | 0.2 | 2.0 | 1.5 | 0.5 | 0.8 |
| 电子 | 0.4 | 0.5 | 0.1 | 8.0 | 4.0 | 0.2 | 10.0 | 0.3 |
| 灵石 | 3.0 | 2.5 | 4.0 | 0.1 | 5.0 | 3.0 | 6.0 | 7.0 |
| 丹药 | 4.0 | 5.0 | 2.0 | 0.3 | 4.0 | 3.5 | 3.0 | 8.0 |
| 粮食 | 6.0 | 4.0 | 8.0 | 0.4 | 0.6 | 2.0 | 0.3 | 4.0 |

### 3.2 行情事件示例

- **灵气风暴**：修仙宗门界灵气暴涨，丹药品质+，灵草需求激增
- **机械入侵**：机械末日世界AI部队进攻，食物/药品需求暴涨，电子垃圾大量倾销
- **瘟疫扩散**：瘟疫荒原疫情蔓延到邻近世界，抗体/防护服跨界价格飞涨
- **蒸汽帝国内战**：金属需求大涨，煤炭短缺
- **修仙天劫**：某大佬渡劫，周边灵气混乱，灵石价格波动剧烈
- **星际外站探索船返航**：大批异星矿物涌入，压低星际外站物价

## 四、传送门能量系统

- **维度能量晶体**：每次穿越消耗，可通过在各世界完成任务获取
- **稳定传送门**：前3个世界免费开放，其余需要能量+解锁条件
- **维度风暴**：随机事件，临时关闭某个世界的传送门1-3天
- **能量效率**：高声誉可降低传送门能量消耗

## 五、拍卖系统（维度漂流物）

### 5.1 什么是维度漂流物
穿越维度裂缝飘来的不明来源货物。玩家通过线索推断：
- 来自哪个世界（决定实际价值）
- 品质如何
- 是否有特殊属性

### 5.2 线索类型

| 线索类别 | 示例 |
|----------|------|
| 材质线索 | "散发淡淡灵气波动" → 修仙界 |
| 外观线索 | "表面有机械齿轮纹路" → 蒸汽帝国 |
| 气味线索 | "有轻微辐射物质气味" → 末日废土 |
| 时代线索 | "包装上有未知文字，字体古朴" → 古代帝国 |
| 能量线索 | "电子检测仪读数异常" → 赛博/星际 |
| 生物线索 | "附着奇异孢子，疑似异界植物" → 瘟疫/修仙 |

### 5.3 世界商人AI竞拍者
- 每个AI绑定特定世界身份
- 对来自"本世界"物品溢价30-80%（熟悉货物价值）
- 对"异世界"物品按最低价值出价（不确定性）
- 特殊：修仙界商人会为任何有灵气残留的物品大幅溢价

### 5.4 拍卖结果揭晓
- 拍到后立即显示：来源世界、品质、特殊属性
- 如果猜对来源世界并打开对应传送门，可当日高价转卖

## 七、物品体系扩展

### 7.1 新增修仙界物品（约30种）

**灵材类**
- 灵石 初/中/高阶（通货，各世界均有价值）
- 灵草 普通/天阶（药材原料）
- 妖兽内丹（稀有，研究价值高）
- 灵木（建材，蒸汽帝国特别需要）
- 灵泉水（纯度极高的水，废土世界天价）

**丹药类**
- 辟谷丹（替代食物，废土必需品）
- 聚气丹（低阶修炼用）
- 筑基丹（珍贵，各大研究机构高价收）
- 疗伤丹（医疗效果显著，全世界通用）
- 毒药/解毒丹（瘟疫世界极度需要）

**法器/材料类**
- 飞剑残片（金属类，蒸汽帝国作为新合金研究）
- 护身符（符咒，废土世界迷信需求高）
- 储物袋（跨维度容器，玩家仓库扩展道具）
- 阵盘（可作电磁屏蔽，赛博世界需求）
- 法袍碎片（高级布料，古代帝国纺织业）

### 7.2 末日特有物品

**核爆废土**
- 防辐射药片（废土高价，其他世界作研究样本）
- 盖革计数器（检测工具，稀有）
- 核电池（长效能源，赛博/星际高价）
- 变异植物种子（修仙界研究稀有品种）

**瘟疫荒原**
- 疫苗样本（医学研究，全世界需求）
- 防毒面具（末日通用品）
- 抗体血清（稀有，高价）
- 病毒培养皿（禁忌物品，黑市高价）

**机械末日**
- AI核心碎片（赛博世界研究材料）
- 机械改造义肢（蒸汽世界爱好者）
- 废弃战斗机器人（零件可拆，或整体拍卖）

### 7.3 各世界货币/通货

不同世界使用不同通货，交易行内部用"维度通证"结算：

| 世界 | 本地通货 | 换算 |
|------|----------|------|
| 核爆废土 | 易货/瓶盖 | 1:0.3 |
| 瘟疫荒原 | 医疗票据 | 1:0.4 |
| 机械末日 | 能量积分 | 1:0.5 |
| 修仙界 | 灵石 | 1:2.0 |
| 蒸汽帝国 | 金镑 | 1:1.2 |
| 赛博魔法 | 数字货币 | 1:1.5 |
| 中世纪 | 金币 | 1:0.8 |
| 星际外站 | 信用单位 | 1:3.0 |
| 古代帝国 | 黄金 | 1:1.8 |

（游戏内统一用"维度通证 ¤" 显示，玩家不需要手动换算）

## 八、界面改动点

- **主界面背景**：从废土店铺 → 悬浮于维度裂缝中的交易行大厅（多个传送门入口可见）
- **顶栏**：日期 · 通证余额 · 当前所在世界 · 传送门能量
- **左侧仓库**：跨维度储物间，标注每件物品来源世界和建议售往世界
- **右侧面板**：NPC来自哪个世界有视觉标识（服装/口音标签）
- **基地**：改为"维度锚点总部"，传送门管理在这里
