# Neon Drift v26-A 验证记录

本轮针对“敌人像静态贴图、攻击行为不易读、图鉴说明不够明确”完成一次表现层扩展。

## 已完成

- 保留当前正向透明图集，不旋转或复用斜向贴图。
- 7 类普通敌人和 4 类 Boss 均补齐职责标签、攻击名称和玩家应对提示。
- 战斗中加入按敌型变化的识别层：侦察环、炮口、蓄能核、冲刺残影、精英标记，以及四种 Boss 专属几何标记。
- 攻击预警期间显示直接可读的攻击名称，并与图鉴的应对说明使用同一份目录数据。
- 新增 3 项回归：威胁数据完整性、图鉴说明生成、敌群/Boss 视觉身份覆盖。

## 本地验证

- `npm run build`：通过。
- `npm test`：核心、回归、静态校验全部通过；回归测试当前 88 项。
- `git diff --check`：通过。
