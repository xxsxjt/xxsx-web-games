# 内容完整度审计 · 2026-10-16

本文是五份并行审计（目录 / 生产规格 / 日循环 / 基地与机器 / 可达性）的结论汇总。
原始报告在 `.claude/wf/content-audit-*.json`。**数字都是对着运行时代码实测的，不是文档抄的。**

审计动机：用户要求「不是一个可玩的版本，是一个整个游戏流程和各种内容都比较完善的版本——
甚至可以只有一两个世界，但不能只有几种物品就让我试玩」。

---

## 1. 目录现状：153 个 SKU，只有 124 个能拿到

| 项 | 数字 |
|---|---|
| ITEM_CATALOG 真实 SKU 数 | **153**（任务书写的 146 是旧数；三种独立计法都是 153） |
| 品类数 | 11 |
| 今天能进入游戏的 | **124** |
| **任何渠道都拿不到** | **29** |
| 只有一个获取渠道的 | 33 / 124 |

29 个死 SKU 集中成三个整品类——它们既不在任何 NPC 的 `bringCategories` 里，
也不在任何一张 `_DISPATCH_LOOT` 表里：

- **装备 equipment**：18 个里 16 个死（只有 multitool / geiger 能从派遣拿到）
- **违禁 illegal**：9 个里 7 个死（只有 ammo_9mm / stolen_goods 能从深处拿到）
- **化学品 chemical**：7 个里 6 个死（只有 fuel_jerrycan_5l 能拿到）

这不是「漏了几个 id」，是**三个整品类在结构上没有入口**。

## 2. 深层问题：122 个能拿到的货，只有「倒买倒卖」一个用途

`evaluateCounterOffer` 接受任何物品，且 `NPC_ROLE_CONFIGS.wantCategories` 的并集覆盖全部 11 个品类，
所以每个拿得到的货至少**卖得掉**——这就是「无用途集合为空」的原因，它是个假象。

真实情况：**没有任何生产/合成系统**。全 `src/` 没有熔炉、没有配方表、没有机器放置逻辑。
`recipe_card` 只是一个 SKU，`ORIGIN_NAMES.craft`（'自制'）只是一个字符串标签。

**全目录只有 3 个 SKU 被机制真正消耗掉**：
`fuel_jerrycan_5l`、`charcoal_bag`（发电）、`filter_cartridge`（净水器）。
其余 122 个非消耗品，功能完全等同于「低买高卖」。

## 3. 11 个世界，5 个是死数据

`WORLD_ORDER` 定义了 11 个世界，但 `VISITOR_WORLDS` 只绑定了 6 个角色到 6 个世界。
没有任何角色会来自：

- 机械末日 `wasteland_ai`
- 灵霄宗门界 `xianxia_sect`
- 中世纪王国 `medieval`
- 星际外站 `stellar`
- 第十一界 · 未知 `unknown`

这 5 个世界只出现在菜单文案和拍卖线索里，**永远不会有商旅来自那里**。

## 4. 机器区是个空壳

`state.baseState.freeGrid` 是真的 `Core.createGrid(4,3)`，UI 渲染得出来，
但**从来没有任何代码往里写过东西**。全 `src/` 对它的 10 处引用分别是：
两次空构造、一次 UI 读取、一个早退的拖放处理器（因为网格永远是空的）。

另外：
- 设施 div 有 `draggable=true`，但**没有 `dragstart` 处理器**，拖放永远不会成功
- 净水器在 `FACILITY_DEFS` 里宣称「回收战利品时提价」（wasteland-shop.js:407），
  **代码里从未实现**——它只在烧滤芯
- 代码里**没有基地等级字段**，`facilities:[]` 数组建了从来没用

## 5. 已修复：拍卖奖池引用了 3 个不存在的 SKU

原代码（wasteland-shop.js 拍卖结算处）：

```js
var POOL = {
  low:  ['junk_metal', 'cloth_roll', 'water_filtered_1l'],
  mid:  ['iron_ingot_1kg', 'circuit_board', 'surgical_kit'],
  high: ['battery_pack', 'whisky_700', 'precision_tool']
};
if (!Core.ITEM_CATALOG[sku]) sku = 'junk_metal';
```

`cloth_roll`、`battery_pack`、`precision_tool` 在目录里根本不存在，
被下面那句静默回退成 ¤4 的废金属。结果：**中高两档花 200 / 500 拍回一块铁。**

现已改为模块级 `AUCTION_POOL`，每个 id 都对着目录核过，
并由 `tests/wasteland-shop.cjs` 钉死：池里每个 id 必须存在于目录，
且每档最便宜奖品不低于起拍价的 60%。

## 6. 日循环的其他缺陷

- 一天是一条线性事务（`endDay` 无任何玩家可见阶段），**没有生产步骤**
- 行情只有 15%/天的冲击掷骰 + 缺货倒计时，**没有均值回归**，长期是随机游走
- 9 个字段生成了但从未显示或写入；3 个字段显示了但从未生成
- **5 处日序列缺陷**，其中包括「谈判中途存档重载」这条路径没被挂载期修复块覆盖

## 结论：该砍什么、该加什么

用户已经明确：**可以砍世界，不能砍物品。**

- 世界数 11 → 只保留两个做深（核爆废土、灵霄宗门界），其余 9 界标注「开发中」
- 物品数：全留，但**必须给它们机制用途**——这就是生产系统的意义
- 生产系统不是「加个玩法」，是**让那些死货活过来**的唯一手段

## 7. 处理结果（同日完成）

实施顺序是按「先让所有货有用途」，不是「再加一个玩法」。

### 7.1 生产系统实装（针对第 2、4 节）

`MACHINE_DEFS` 6 台机器 + `RECIPE_DEFS` 20 道配方，数据在 `src/wasteland-core.js`，
逻辑在 `src/wasteland-shop.js`。三条规则由测试钉死：

| 规则 | 测试断言 |
|---|---|
| 成品比原料值钱 | 每道配方成品 ≥ 原料的 1.5 倍（实测 1.8–3.1 倍） |
| 炼废了是真亏 | 副产物价值 < 原料，且 > 0 |
| 没电不干活 | 断电时批次原地等待，不推进天数、不再吃料 |

机器区 `baseState.freeGrid` 真正启用了：买机器要钱（¤200–650）、要按世界买、要摆得下。

### 7.2 可达性 29 → 0

补的入口：

- 拾荒者增加 `equipment` / `illegal` / `survival` / `tool`（装备与违禁品此前毫无入口）
- 行商增加 `chemical`（机油、溶剂、甘油）
- 工地采购增加 `equipment` / `repair` / `digging`
- 深入禁区战利品补 `signal_jammer`（¤350 超过访客带货上限 320，只能靠派遣拿）

**用真实访客生成器采样复核**（每界 400 天，不是靠正则猜）：
目录扩到 **179 个 SKU，可达 179，不可达 0**。单渠道货 41 个。

### 7.3 世界：11 → 2 正式 + 9 开发中（针对第 3 节）

`WORLD_ORDER[].status` 新增 `playable` / `wip`。核爆废土与灵霄宗门界为 `playable`，
其余 9 界在界门面板显示为不可点的灰卡并标注「开发中」。

商旅角色重新绑定：废土界 4 个（拾荒者/行商/游医/工地采购），
宗门界 4 个（采药人/游方丹师/散修/藏家），情报贩子中立。

每天选一个世界、在随机地点开张，**当天只能换一次**。

### 7.4 净水器的空宣称补上（针对第 4 节）

`FACILITY_DEFS` 里净水器宣称的「回收战利品时给水与化学品提价」现在真的实现了：
只作用于 `origin==='salvage'` 的水/化学品，只在通电时生效，提一档封顶。

### 7.5 本轮由浏览器实测抓到的两个 bug

1. **`NPC.WORLD_ORDER` / `NPC.worldById` 没导出** —— 界门面板渲染出来是空的
   （有标题、没有卡），而且所有转场都会被静默拒绝。测试完全没覆盖这块。
2. **`chooseWorld` 忘了置 `worldLocked`** —— 玩家可以反复转场，
   每次重掷一批客商，刷到满意为止。这正是代码注释里说要防的漏洞，但没真做。

两个都补了测试。第 2 条尤其说明：**注释里写了规则，不等于代码执行了规则。**

### 7.6 仍未做

- 「时空」这个名字是遗留物：游戏里**没有穿越时间的能力**，只有跨界门。
  此前要求改名，尚未执行（涉及标题、菜单文案、文件名与存档 key）。
- 基地等级作为主轴、仓库与机器区的可视化仍未做（分区逻辑已实现）。
- 拍卖线索文案里仍提到「机械末日」「星际外站」等开发中世界的名字。
