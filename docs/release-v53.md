## 存档与兼容

三款新战役分别使用 `xxsxSalvageExpeditionV1`、`xxsxEchoDeckV1`、`xxsxRelayDefenseV1`，不写入原短局分数或舰站共享奖励。旧限时打捞、记忆试炼与反应挑战在同页可展开区域保留，旧入口和旧档案键继续可用。

新战役的行动档案先校验待写数据，再保留上一份有效备份，并验证主档写入。坏档字节会在后续替换前保留到 `.rejected`；主档损坏时可恢复有效备份。开新方案需先点「更换方案」，取消选择可继续原局。失败或完成只结算一次，空货舱撤离不增加完成次数。没有跨标签页并发写入合并，也没有云存档。

探索与卡牌每次行动保存。塔防每次调整及进攻中约每三秒保存，刷新后恢复为暂停；离开玩法或页面进入后台也会暂停，不补算离线进攻。射击保留原局外成长存档，仍不支持局内刷新续玩。

`src/campaign-core.js` 负责新战役的保存与实时暂停；三款玩法各有独立状态模型。旧共享游戏适配层仍在，尚未完成全站生命周期拆分。

构建保留 V51、V52 已发布哈希 URL 和原地址别名，新页面只请求当前版本资源。同版本反复构建不会保留每次未发布编辑的哈希资源。

## 实际验证

- 构建后 `npm test` 退出码 0，共 228 条 PASS/✓ 输出。这是规则检查数量，不是玩家试玩次数。新增检查覆盖氧气、货舱、工具、热度、卡牌能量与牌区、一次性研究/奖励、塔防造价/升级/回收、护盾吸收、分裂与过载、暂停、存档恢复与坏档保留，以及射击三条路线的实际效果和不叠加重算。
- 合法行动模拟走通三层核心回收、三种起始卡组各一条九节点通关路线、三张塔防地图各一条十二波通关路线；未修改玩家资金、生命或敌人以绕过规则。未布防会失守，耗尽氧气会丢失货物价值。这些检查证明存在通关路线，不证明所有种子、策略或玩家体验均衡。
- 浏览器实际完成卡牌首战，领取反向回收、进入研究间、强化脉冲，刷新后保留资金、卡组和下一监守节点；打捞实际移动、装载研究数据，刷新后位置、氧气、热度和货物保留；塔防实际部署两座塔、开始第一波、击破信号、暂停，刷新后保留炮位和资金并保持暂停。
- 浏览器打开相位突击射击路线，HUD 显示对应主炮与护盾参数。云浏览器出现长帧间隔并触发已有卡顿保护，本轮不据此宣称连续操作手感或实机帧率通过；路线效果由规则回归检查验证。
- 同源 iframe 检查三款新战役在 320、375、414、768px 和 320px/200% 文字下的可见按钮与横向边界；覆盖打捞货舱、塔防暂停布防及卡牌实际手牌。修正大字模式下炮位按钮文字溢出；普通字号按钮高度至少 44px，打捞 320px 地图格宽约 48px。iframe 检查不等于实体手机测试。

没有附送截图，没有增加第三方运行依赖。发布前读取 GitHub 最新分支，采用有父提交的正常更新，并核对远端文件树与本地源码、素材及构建结果的 Git blob SHA；保留 AGPL 许可证。

## 仍需打磨

三款原短局现在有独立战役与不同的核心决策，但长期重复游玩、关卡节奏、手感和数值平衡仍缺少玩家记录。卡牌节点顺序固定，打捞地图为三层手工布局，塔防仍只有三张地图。射击尚未完成全部编排遭遇、Boss 深度和独立美术升级。未做全游戏实体手机触控、完整真人通关、实机帧率或多标签冲突实验；更大架构迁移和跨风格新作品仍属于后续路线。
