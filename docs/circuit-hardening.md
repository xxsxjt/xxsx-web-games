## 玩家可见变化

十八关的旋转工具下方新增原生折叠区 **“端口诊断 · 免费只读”**。默认收起，展开状态在本页旋转/撤销等重绘后保留，不存进档案。

诊断只描述当前看得见的连接：

1. 输入外接口、输出格是否通电，以及输出外接口是否接通。
2. 尚未通电的 ◆ 中继和已经通电的 × 危险节点，使用当前行列坐标。
3. **通电侧悬空接口**总数和前三处的坐标/朝向/原因：接到空白、与邻格接口不吻合、越出棋盘。其余仅显示数量，避免手机上一长段诊断挤占棋盘。

例如首关会描述“第3行第1列向右与第3行第2列接口不吻合”，而不会给出正确方向、应旋转几次或参考路线。每次接线操作后按当前棋盘重新计算；原有检验、失败原因、存储告警、影响星级的提示和星级显示仍然保留。

**悬空端口不是新增失败规则。** 现有电路允许多余端口和支路；诊断明确提示“不必全部消除”。战役仍只以输出接通、全部中继通电、所有危险节点隔离判断成功，旧随机挑战仍只以输入到输出的真实连通性判断成功。

## 模型接口

两个模型均新增纯读取接口 `diagnose(board)`，不调用 `hint` 或写入棋盘：

| 字段 | 含义 |
| --- | --- |
| `powered` | 从输入沿双向吻合接口可达的格子，不包含未通电孤岛 |
| `inputConnected` | 当前输入外接口存在 |
| `outputReached` | 输出格已被供电 |
| `outputConnected` | 输出格供电且输出外接口接通 |
| `openPorts` | 通电侧未接通接口，元素为 `{index, port, next, reason}` |

`port` 使用现有位掩码：上 1、右 2、下 4、左 8；`next` 在越界时为 `null`；`reason` 为 `blank`、`unmatched` 或 `edge`。输入/输出的指定外接口不计作悬空端口，不允许左右行边缘绕行。

战役接口额外返回 `missingRelays`、`danger` 和原有规则下的 `solved`。随机挑战保留其四边终端规则和缺少 `startPort` / `endPort` 的历史状态默认值（左输入、右输出）；未给有效棋盘时返回 `null`。

诊断不读取 `solutionMask`、`path`、`solutionPath` 或 `scrambled`，不搜索解法、不提供旋转建议、不自动操作棋盘。数组均为新计算结果，调用者修改返回值不会改到棋盘。旧随机挑战仅增加兼容 API；其可见界面在共享 `src/game.js` 中，按此次独占边界不改动，不能声称旧随机挑战已增加可见诊断面板。
