# 下一款作品：借来的十秒

状态：设计方案，尚未作为第七款游戏上线。不是另外一套数值成长，也不必接入霓虹突围世界观。

## 核心规则

玩家每次拥有十秒。第一轮的移动、搬运和开关操作在下一轮由一个回声角色原样重演；玩家控制新的角色。最多保留三个回声，第四轮开始前必须删除其中一个。删除回声同时删除它对场景的贡献，需要重新规划，不能无限堆叠角色解题。

每个回声只使用自己录制时的工具。实体位置会影响重演：旧路线被箱子挡住，回声就会停在那里；旧角色仍可压住地板按钮，但不会聪明地改道。用清晰的时间线显示阻塞时刻，失败立即重录，不要求猜测隐藏规则。

## 一局实例

房间有一条激光走廊、一个必须持续按住的断电按钮和一个需双人推行的货箱。

1. 第一轮，去断电按钮停留，录制回声 A。
2. 第二轮，借 A 断电的七秒穿过走廊，打开另一侧门，录制回声 B。
3. 第三轮，提前把货箱放到 B 的路线旁，与 B 一起推过门。若推箱导致 B 迟到，门会在箱子经过前关闭；玩家要重录或调整起步时刻。

乐趣来自安排自己与过去自己的协作，同时接受每次操作留下的约束。成功不是点完三个指定按钮，而是可用多种时间顺序达成同一目标。

## 第一版范围

- 六个短房间，分别教移动回声、持续开关、搬运、相互阻塞、删除回声、组合解。
- 一个可自由试验的房间，包含两条通路与可移动家具，允许至少三种经过测试的解法。
- 手机浮动摇杆和大动作键；时间线允许暂停检查，重录单个回声；可以切换不限时练习。
- 不做永久属性、随机掉落、签到、排行。先验证回声协作是否值得反复尝试。
- 开发门槛：第一个房间真实可解、至少两种有效顺序、玩家能理解一次阻塞失败，再扩展关卡。

## 备选方向

### 规则回收站

场景中的“重力”“透明”“追踪”是可拆卸的模块。玩家只能同时携带两条规则，把重力装到门上让它下落，把透明从玻璃转移到自己身上通过摄像头。规则移动改变所有相关物体，回收一条规则会破坏之前搭好的通路。第一版只验证三种规则、五种物体，避免变成大量不一致的特例。

### 盲区邮差

城市只在玩家看向的方向存在，转头会使视野外街区按配送单重排。需要保存的地点可用有限的路标固定；包裹的重量、温度和收件时间会互相冲突。先用一个可重排的四街区地图验证路线记忆与主动制造盲区，再考虑更多内容。

优先做《借来的十秒》：输入规则简单，失败原因可视化，能用静态网页实现，首个完整房间就能判断玩法是否成立。
