# V59：叠印工单 A01

## 交付范围

- 总站加入第九款作品《叠印工单》，入口 `games/overprint.html#level/01`。仅 A01 一张 4×4 工单，不设局内或通关存档，不改既有游戏入口、规则及存档。
- 点格只预览，独立的「压印」才会消耗印版。`+`、`→`、`!` 区分新印、覆盖和留白误印；越界不能压印，误印留白可撤销。两个横纹锚点有不同的补印顺序，详见 [A01 规则与解法](new-game-lab-v59.md#a01--搭版首关规格)。
- 固定保留 V58 的全部内容哈希资源（包括被替换的总站脚本和配套目录），避免已缓存的页面因更新而失去资源；未改变站点部署配置。

## 构建与本机验收

- `npm run build`、`npm test`、`git diff --check` 均通过。主页 HTML/CSS/JS/目录 gzip 合计 12,495 bytes（不含图标），清单含 47 个本版文件、87 个固定历史资源和 16 个别名。历史资源逐项 SHA-256 与 V58 Git 树一致；V58 缓存首页仍能渲染原八款，旧 `play.html` 与 loader 混合回放 46/46 通过。
- Orca 从本机 `dist/` 总站卡片进入 A01，地址归一到 `#level/01`。320×680 下用鼠标指针完成主解，差异从 8 降到 0；另试过留白误印、版数用尽、撤销、两个方向越界、胜后继续与重开。刷新、返回九款作品的总站并再次进入，均在 A01 从空印面开始。
- 531 CSS px 用 Orca 的真实浏览器按键路径（Tab、方向键、Enter／空格）完成另一解。选格与提交分开，印版归零后焦点留在可用控件，获胜后焦点到「撤销」；键盘撤销、重开通过。
- 移动模拟宽度 320／375／414／768 CSS px 均无横向溢出，最小工作格分别为 59.6／73.4／83.1／49.4 CSS px，控件至少 44 CSS px。320×680 的「压印」需纵向滚动可达。输入日志确认点击是 `pointerType: mouse`，不能算作真实触屏；实体设备和未知解法的新玩家试玩未做。
