# V52：游戏图标、解谜战役与战术决策

日期：2026-10-07。基线：V51；GitHub 基线提交 `21eab39b30b7bbb12cef8f9467338afb1c3f9a3e`。

## 可见变化

- 总站「关于」直接打开 GitHub 仓库。六款作品改用六张独立生成的游戏图标，首页明确区分战役与短局挑战，全部仍标注测试版。图标是身份插画，实际玩法没有对应的新角色或场景承诺。
- 黑盒解码新增十八关手工电路战役，按接线、中继、隔离、锚点、复合、终局递进。过关需要同时接通输出、点亮所有必经中继、隔离所有危险端口。可以切换旋转方向、撤销、查看带方向的提示、重玩并优化星级。当前接线每步保存，切换关卡重新接线，保留各关最佳成绩。
- 战术选择敌人后先显示预计伤害与剩余生命，再按「确认射击」执行。新增消耗 1 AP 的警戒、掩护和推击；警戒在敌人移动进入射程时反击一次，掩护减少本轮伤害，推击改变位置并打断下一次行动。远距离攻击掩体内目标减伤，抵近后可忽略这项减伤。
- 战术第二舱段有三格反应堆泄压区，每三回合喷发，界面显示倒计时；启动两座冷却阀可永久关闭。突击机每次推进两格。补给加入警戒强化与移动范围扩展；新局移动不再刷分。
- 旧舰站大厅的介绍同步修正为战役原型与短局，不再宣称「两款完整主线」。新解码战役的进度与旧共享档案分开说明。

## 存档与兼容

新解谜战役使用独立键 `xxsxCircuitCampaignV1`，不增加旧随机七层挑战的总分或舰站奖励。原随机挑战保留在同页可展开区域，原文件和存档不删除。新档验证电路形状、锁定节点、关卡与撤销历史；异常字节在新操作写档前保留到 `.rejected`。

战术仍使用原 `neonBorderTacticsSaveV1` 与已校验的待提交、备份和恢复路径。新行动带 `ruleset: 2`；旧进行中档案不增加反应堆伤害、不改变原推进速度与移动计分。新增姿态随行动档案保存。原入口与射击存档保持兼容。

构建保留上一发布代的完整哈希资源清单，包括与新版本暂时共用的文件，连续重建不会遗漏后续变更的旧文件。新页面请求本版哈希资源；原 V50 URL 别名继续保留。

## 实际验证

- 构建后 `npm test` 退出码 0，共 210 个 PASS/✓ 检查输出，无失败。这是检查数量，不是完整游玩次数。新增检查覆盖十八关已知解、中继与危险约束、旋转与撤销、星级提示代价、存档恢复与坏档保留，以及警戒、掩护、推击、反应堆、移动范围、旧规则和指定技能目标。
- 浏览器实际走通解谜第一、二关三星、下一关解锁、旋转后刷新续玩及撤销。战术走通移动、目标伤害预览、警戒命中、掩护、保存返回、刷新恢复和确认射击。
- 总站与解谜在同源 iframe 的 320、375、414、768px 宽度及 320px/200% 文字下检查控件边界，无横向溢出。320px 解谜电路格约 48px，动作控件至少 44px；320px 战术开局与操作按钮边界通过。未把 iframe 检查当作实体手机测试。
- 正式 `dist/` 首页六张哈希图标加载成功；入口资源、源文件、上一代缓存资源的内容哈希通过检查。没有新增或附送截图。

总站 HTML/CSS/JS/目录的 gzip 构建体积为 6,265 字节，不含图片。六张 512×512 WebP 图标合计 392,364 字节。图标生成方式与完整最终提示词见 [图标记录](game-icons-v52.md)。

## 尚未完成

这一版提高了解谜与战术的决策密度，尚无长期试玩数据证明整体可玩性达到目标。三款短局的核心玩法没有重做；射击三种构筑路线、编排遭遇、Boss 深度升级仍待完成。战术保留原三张地图，没有新增完整地图库或干员美术。新解谜没有多人、云存档或跨标签写入冲突处理。

没有实机帧率、加载时延、触控连续性、完整十八关玩家通关或战术全战役平衡记录。共享适配层仍较大，新解谜已独立成模块，其余游戏没有全部完成生命周期拆分。
