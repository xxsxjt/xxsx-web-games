# Neon Drift / 霓虹突围 — 现有游戏集合说明

本仓库维护公开静态站点 [新伊甸游戏厅](https://neon-drift-roguelite.xxsxjt.chatgpt.site)。当前版本为 V50：在 V49 的过载协议基础上，加入敌机越过底线的 BREACH 冲击、连杀中断与分数惩罚。过载协议，让连杀、精英和 Boss 击破积累能量，在弹幕失控或 Boss 护盾窗口里换取一次范围输出、清弹幕、护盾恢复和短时火力爆发。两款独立主线和四种小游戏共享舰站资源、委托、每日指令与作战日志。移动端和桌面端都可直接游玩；无需登录或服务器端服务。

## 站点结构

- `#arcade`：六种可玩模式的目录、共享档案摘要与站点公告。
- `#game/expedition`：霓虹突围，实时弹幕 Roguelite。
- `#game/border`：边境战术：失落站，三人小队回合战役。
- `#game/relay`、`#game/lab`、`#game/salvage`、`#game/blackbox`：四款规则独立的小游戏。
- `#station/<view>`：舰桥、机库、航线、图鉴、攻略、构筑、局外协议、委托、每日指令、作战日志等站点内容。

每款游戏都有独立开局、规则和记录。星尘、情报、模块、研究和跨游戏委托回到同一份本机指挥官档案。

## 边境战术：失落站

三名干员穿过三个舱段：突击手负责压制，医护兵负责急救，工程师可打断敌方行动。每名干员每回合有 2 点行动；移动、攻击、技能与启动终端都会消耗行动点。敌方攻击会在执行前显示预警格，掩体会减轻伤害。第 1、2 舱段清场后可选补给；最终舱段启动终端并抵达撤离格才算完成行动。

每个战术动作都会写入 `neonBorderTacticsSaveV1`。档案有主记录、待提交记录和上一份有效备份；读取时先校验，再使用修订号最新的有效档。损坏内容会原样保留，重新开局前也必须能写入隔离副本。结算使用行动编号去重，刷新不会重复发放奖励。

## 本机数据与已知边界

指挥官档案 `neonDriftProfileV1` 使用 schema 11，记录六种模式的成绩、共享成长和当前每日舰站指令。V46 起写入采用带修订号的待提交档、主档和上一份有效备份；旧版直接 JSON 仍可读取，主档损坏时会回退到可读副本。V48 的战术契约和 V49 的过载能量只属于当前远征，不会写入跨局进度；完成契约或释放过载会在当前波次改变战斗行为。每日指令按本地日期轮换，进度和奖励领取状态也只保存在当前浏览器；不同设备之间不会自动同步，也没有云端排行榜。

失落站进行中的战役支持离开、刷新和关闭后继续。霓虹突围的实时战斗仍只在当前页面运行，刷新会结束这一局；短局也只在结算时记录。信号中继、回声实验和深空打捞切到后台时会冻结倒计时，回到页面后继续当前进度。浏览器清理站点数据或禁用本地存储会移除本机档案。

## 开发与检查

```sh
npm run build
npm test
```

构建会复制 `index.html`、`src/` 和发布所需美术资源到 `dist/`。回归包含核心机制、既有模式、跨站点档案、边境战术存档与战斗，以及源文件和发布文件一致性检查。

`tests/viewport.html` 用于检查窄屏、常见手机尺寸与横屏 CSS，不会部署到站点。自动化检查不能替代实体手机上的触控和长时间平衡测试。

## 源码地图

- `index.html`：站点结构、独立游戏页和脚本加载顺序。
- `src/game.js`：实时远征、过载协议、站点导航、共享档案、奖励和委托。
- `src/border.js`：边境战术回合规则、本机断点存档与恢复。
- `src/arcade.js`、`src/blackbox.js`、`src/runtime.js`：小游戏生成、规则与计时器生命周期。
- `src/catalog.js`、`src/core.js`：装备数据、共享战斗计算和输入辅助。
- `src/styles.css`：全站及各玩法响应式样式。
- `design.md`：Hallmark 锁定的全站设计系统；`.codex/skills/hallmark/`：项目级 Hallmark 技能副本。
- `scripts/build.mjs`：静态构建。
- `tests/`：核心机制、应用回归、边境战术和静态发布校验。
- [`docs/plan-v41-border-tactics.md`](plan-v41-border-tactics.md)：当前计划和后续路线。
